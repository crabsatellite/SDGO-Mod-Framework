# 活动扭蛋币种修复独立包

`SDGO-CapsuleCurrencyFix-<版本>.zip` 是 SDGO Mod Manager 客户端配置包，包含本 Mod 的 DLL、管理描述、
Mod 清单、所需符号片段和说明。基础框架需另行安装。

关闭目标游戏，在 Manager 选择客户端，点击「导入客户端配置包」导入该 ZIP，然后启动游戏。
检查步骤见[使用说明](../../docs/capsule-currency-fix.zh-CN.md)。

本包不包含扭蛋机编辑器的文件，导入不会改动已有扭蛋目录资源。符号片段中的 `grid.data`、`grid.find`
也被其他 Mod 使用，不要单独删除。

支持客户端 `GOnline-54BE1568-00C97000`。停用时在 Manager 点“显示开发信息”，于「修复归档」关闭本修复并重启游戏。
