# 阿普萨拉斯 III 变形卡死修复

`transform_input_fix` 是自动生效的客户端修复，位于 Mod Manager 的自动修复归档中。
安装后重启客户端，无需设置。机库、等级、经验、强化和涂装数据均由原流程保留。

从 `24788` 形态出击时，第一次变形会切换到模型 `1957`，随后请求该模型没有的
`change_ma`；反向请求也可能遇到其缺失的 `change_ms`。原生动画接口返回零句柄，
但旧动画仍可能继续产生其他句柄的事件，使变形状态一直等待，移动和攻击随之锁死。

Mod 仅处理 `24787/24788` 两形态之间、变形模式为 3、动画句柄为空且旧事件仍存在的
分支，调用原生空事件路径已有的等待状态流程。形态提交、武器切换与清理由原生
变形退出函数完成。正常变形动画和其他机体继续使用原流程。

当前缺失的模型动画仍然缺失；这项修复负责恢复该状态的正常退出。

验证已覆盖实际 DLL 的调用约定、触发范围和数据保护，以及 740 条有明确替代边界的
原生函数回放观察。原先 96 次保留旧动画的空句柄调用均恢复为请求原生等待，原函数
代码保持完整。这些结果不能代替整场客户端实战。
