# 好友机体赠送（可选）

[English](friend-unit-gift.md) · [返回功能目录](../README.zh-CN.md) · [好友列表修复](friend-list-fix.zh-CN.md)

把自己拥有的一台机体送给已确认的好友。赠送转移原机体实例，保留等级、成长、技能、零件、涂装和原取得日期；不会复制一台新的机体。

默认关闭。服主在 SDGO Mod Manager 的「好友机体赠送」中打开「启用好友机体赠送」，并调整资格规则；客户端只在服务器支持并开启时显示赠送入口。赠送预览复用原生获得机体卡片，显示原有模型、武器、技能和等级；机体选择、可选寄语和确认按钮也复用现有原生控件及素材，不需要修改游戏 EXE 或资源归档。

## 赠送与收取

1. 在主页面右上角 **USER LIST** 或聊天好友页右键已确认的好友，选择「赠送机体」；在线或离线的好友都可以接收。
2. 入口打开原生「机体管理」，双击要赠送的机体。在原生机体信息卡片核对名称和等级，可以填写寄语；核对服务器预检结果后，再确认赠送。
3. 机体进入待接收保管状态，发送者暂时不能使用它。接收方可以离线，登录后再从保管库处理。
4. 接收方在保管库的机体赠礼页查看原有样式的机体条目。点击机体图标打开原生信息卡片，查看赠送者、时间和寄语，选择接受或退还。寄语放在信息卡片中，不占用保管库条目。

信息卡片保留原生模型、机体名称、等级与技能；右下角使用现有素材统一绘制寄语和确认区域。

赠送选机时，左右箭头每次移动一页，圆点选择当前页组中的页面；箭头也能跨页组往返，第一页和最后一页不会越界。
可以在任意页双击已拥有的机体打开信息卡片，取消后仍可继续浏览、重新选择。

原生信息页面关闭或被替换时，会清理旧控件绑定；重新打开后绑定当前页面，避免切换场景后继续访问已销毁的控件。

接受时需要接收方有空机位。空间不足会保留礼物，可腾出机位后再收取，也可以退还。
退还时优先放回发送者原机位；原机位已占用时使用其他空位。发送者机库已满时，机体继续保管，待发送者腾出空间后取回，不会强塞或丢弃。

普通奖品和这类机体赠礼分别处理。「一键领取」不会替玩家接受或退还机体赠礼，原生礼物的删除操作也不等于退还机体。

## 赠送条件

默认沿用旧赠送规则，发送者需要同时满足：

- 总战斗场数至少 20 场。
- 玩家击坠统计至少 1。
- C、CS、CR、B、BS、BR、A、AS、AR、S、SS、SR 共 12 个等级分类，每档拥有至少 2 种不同机体。

这些资格门槛可由服主在 Manager 调整。以下机体和关系限制始终有效：

- 必须是发送者当前拥有的永久机体，不能送给自己，发送时双方须为已确认且未屏蔽的好友。
- 锁定、出战、辅助、保存编队或队长引用中的机体不能赠送。
- 已到期、受禁止状态限制或仍在其他待处理赠送中的机体不能再次赠送。

选择机体后状态发生变化，服务器会重新核对并拒绝过期选择。资格由服务器判定，客户端不能改变条件或指定他人的机体。

已装备的技能零件随原机体一起转移。客户端在预检前会读取所选机体的现有详情，请等待读取完成；预检和取消不会改变机体所有权。

## 赠礼记录

已接受机体的详情提供赠送来源入口，可查看赠送者、赠送时间和寄语。记录绑定机体实例，不会改掉同型号所有机体共用的介绍文字。

赠送时间由服务器记录；它与机体原取得日期分开保存。寄语保存在 Mod 自有的 Unicode 数据中。

## 配置与兼容

客户端组件为 `friend_unit_gift_client`，Agent 和 World 组件为 `friend_unit_gift_server`。使用匹配的框架运行文件，通过现有更新器分发。服务端沿用原生数据库会话，自动维护自有 schema，不需要玩家配置账号、SQL 或后台程序。

在 Manager 中关闭「启用好友机体赠送」并重启后，不能再发起新赠送；已有待接收、退回待取回的机体仍可处理，已接受的赠礼记录保留。卸载整套服务端组件前，应先处理尚在保管中的机体。

发送后超时或断线，界面可能显示「结果待确认」。这不表示已撤销，也不要据此再次发送；重新连接后查询原请求结果，并以保管库和库存为准。接受和退还只会有一个最终结果。

不支持本协议的服务器不会显示可用赠送入口，普通好友、邮件、商店赠送和保管库流程继续使用原生处理。

## 开发者说明

好友菜单复用现有蓝色背景条及按钮的透明、悬停和按下状态。扩展后的菜单由原生弹窗函数按右键位置定位，
后台能力刷新不会重置菜单坐标。保管库关闭后，赠礼界面丢弃旧页面的控件引用，再次打开时绑定新页面。

原生好友赠送测试支持 `--phase picker-pagination`，复用已有测试账号与机体绑定，通过隔离的虚拟鼠标输入核对圆点、
相邻页箭头、跨页组、后续页双击选机及取消重开。此阶段不确认赠送，并核对原机体数据保持不变。
环境和账号要求见[原生测试说明](game-test.zh-CN.md)。
