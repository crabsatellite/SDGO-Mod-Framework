# 扭蛋卡、候选池与价格显示：开发者说明

[返回扭蛋机编辑器](capsule-catalog.zh-CN.md)

## 卡面

原始 GDT 中引用的 341 种卡片保持原 SPR 两态，不重绘。另有一些机体的旧参考卡来自历史脚本生成，存在等级条破损、
星空背景缺失、两态相同等问题；这些卡使用同机体源图、完整原生等级框和头像裁切重建，生成物和来源须通过联系表核对。
没有核实卡图的机体不会用全身小图、英文名称和自制边框代替。

边框、原版内边和图片窗口按原生像素坐标保留，不抹掉原版内边，也不额外增加留白。新卡保持 183×107 的逻辑尺寸，
放入 256×128 的纹理并使用精确子 UV，避免对非二次幂整图采样引入边缘缩放或缝隙。

上传 PNG 只开放已有可靠原生框的 A/B/C 系列；S/SR/SS 暂无验证过的重建框。原生框线、等级条、稀有剪影和页脚由统一合成器处理，
图片不需要预先带框。编译版本为 8，输出 manifest 记录上传 PNG 哈希和裁切坐标。编辑器只接收处理好的 PNG，
不运行 AI、不下载模型，默认配置也不含高清图片覆盖。

## 自定义候选规则

候选策略绑定只读原始快照，原生基础候选保留；新增候选只允许 SR，或完全没有 `tbl_MixTreeFile.OutUnitID` 配方记录的 SS。
图纸商品未开放、材料缺失或路线暂时阻塞都不等于没有设计图。普通 S 和有配方 SS 不自动进入自定义池。
初始化、候选增删改、导入校验和 UI 选择器共用此限制；原生候选可下架后恢复。

38 台 AS/BS/CS 没有核实过的同机体两态扭蛋卡，不自动派生固定机。初始化报告把建议根、实际配置根、未配置根与受影响的
变形机体分开列出（参考服：156 个建议根中配置 100 个，56 个未配置根及关联依赖导致 66 条暂不可达记录）。

## 列表位置

原生 `FUN_007A6070` 将 0033 表倒序放入内部列表，`FUN_0079E620` 再按页内索引正向读取，每页 8 台。
例如 105 台时第 1 页依次为 105、104、103 … 98 号机，因此 103 号在第 1 页第 3 格，79 号在第 4 页第 3 格。
配置顺序和实际游戏位置在 UI 中分别展示，`placements.json` 保存实际可见位置。

## 价格显示与模板定价

0033 的价格字段在 `+0x0F`。原生列表函数把它转成文本写入 8 个通用 `PointStatic` 控件，并启用价格和 GB 标签。
缺少 0101 Coin 变体时，原生选择逻辑回退到 GP；不应为修列表价格补造 Coin 机台。

原版 UIR 中第二个价格控件的默认文本也是 1200，而 `CUIStaticText` 的延迟缓存重建路径把新旧相同的文本视为无需更新，
因此首次没有建立字形，价格显示为空。修复只清空 `uirs/1161.uir` 中 8 个价格默认值的首字符（整份资源只改 8 个字节，
布局、坐标和字体不变），使首次写入实际价格时触发原生字形构建。运行时只放行这一张额外 UI 资源，并检查声明的哈希。

新建机台默认继承模板价：全 A 14800，全 B 7500，混合模板按原价 1200 或 1600；显式提供价格才统一覆盖，既有手动价格保持不变。
自动初始化按原版价格占比选择模板，普通 C 补位跨池轮换，A/B 与全部权重不改。
