# 机体列表三维预览加载保护

本自动修复保护原生机体列表的三维预览加载路径。顶点或索引缓冲上传失败、模型加载失败时，拒绝启用失败对象，该格改用游戏已有的二维缩略图，保留库存条目与选择功能。

## 安装与行为

通过 Mod Manager 或服主提供的客户端包或更新安装，重启客户端生效。本组件没有玩法参数，位于 Manager 的自动修复归档。

上传成功时保留原生指令。失败处理限定在机体列表的一次预览请求内：跳过无效复制和不配对的解锁，完成原生文件读取，再用原生析构函数释放刚创建、尚未登记的资源，并向上层报告加载失败。临时字符串、候选模型、渲染临界区和行任务分别保留对应的原生清理路径。

二维缩略图回退只影响失败的那一格，不修改模型文件、机体定义、账号数据、库存顺序、战斗或显卡驱动设置。

## 范围与诊断

本组件不拦截通用堆释放，也不吞掉无关访问异常；它不能确定已经损坏的模型对象由谁写坏，也不宣称修复无关堆损坏。

日志警告标出失败的预览及操作。开发者可通过 `sdgo/hangar_preview_guard_observer.h` 读取作用域内的失败、回退和清理计数。GPU 故障注入仅由 GameTest 使用，不放入正式组件。

针对性测试加载实际 DLL，覆盖两种顶点布局、索引上传、原生所有权、源文件关闭、锁配对及设置器的字节返回 ABI。原生验收对原版客户端的顶点缓冲创建调用注入一次失败，检查清理及真实返回账号、重登录后的同槽位恢复，并对比全部库存的身份、槽位、等级和保护标记；异步详情缓存的就绪状态单独观察。实际画面读回确认打开了机体管理；短暂回退可能在截图之前已经恢复。
