# 机库三维预览加载保护

本自动修复保护原生机体列表及机库主展示的三维预览加载路径。顶点或索引缓冲上传失败、模型加载失败时，拒绝启用失败对象。列表格子改用游戏已有的二维缩略图，保留库存条目与选择功能；主展示进入原有的空模型分支。

## 安装与行为

通过 Mod Manager 或服主提供的客户端包或更新安装，重启客户端生效。本组件没有玩法参数，位于 Manager 的自动修复归档。

上传成功时保留原生指令。失败处理限定在列表预览请求或已核验的机库主展示调用中：跳过无效复制和不配对的解锁，完成原生文件读取，再用原生析构函数释放刚创建、尚未登记的资源，并向上层报告加载失败。临时字符串、候选模型、渲染临界区和行任务分别保留对应的原生清理路径。主展示调用方已有空模型检查，并负责释放自己的渲染锁；保护不代替它解锁，也不对主展示执行列表缩略图操作，后续原生加载仍可重试。

二维缩略图回退只影响失败的那一格，不修改模型文件、机体定义、账号数据、库存顺序、战斗或显卡驱动设置。

## 范围与诊断

本组件不拦截通用堆释放，也不吞掉无关访问异常；它不能确定已经损坏的模型对象由谁写坏，也不宣称修复无关堆损坏。

日志警告标出失败的预览及操作。开发者可通过 `sdgo/hangar_preview_guard_observer.h` 读取作用域内的失败、回退和清理计数。GPU 故障注入仅由 GameTest 使用，不放入正式组件。

新增的 `SdgoHangarPreviewGuardGetStatusV2` 保留 V1，单独统计机库主展示的请求、成功与失败。实际 DLL 测试覆盖 32 字节顶点布局的缓冲缺失、上传失败及空映射、索引失败、模型返回失败、源文件／根节点／候选对象清理、调用方锁所有权及后续成功加载。这些测试不代表所有显卡设备丢失或驱动异常都能恢复。

隔离的普通 PvP 回归可使用 GameTest SDK 0.1.44 的 `MainHangarPreviewFault=1`，要求本组件至少为 0.2.0。一次性 VB32 创建失败由正式组件的线程局部主展示作用域限制；战斗返回用例要求注入恰好一次、完成原生根节点／源文件／候选模型清理、随后成功加载主展示并收到真实大厅返回。页面、任务和 FPS 场景拒绝该选项。其他测试保持默认零；它不是玩家配置。

针对性测试加载实际 DLL，覆盖两种顶点布局、索引上传、原生所有权、源文件关闭、锁配对及设置器的字节返回 ABI。原生验收对原版客户端的顶点缓冲创建调用注入一次失败，检查清理及真实返回账号、重登录后的同槽位恢复，并对比全部库存的身份、槽位、等级和保护标记；异步详情缓存的就绪状态单独观察。实际画面读回确认打开了机体管理；短暂回退可能在截图之前已经恢复。
