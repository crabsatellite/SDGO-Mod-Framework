# 公告与展示规则

打开 **SDGO Mod Manager → 服主工具 → 公告与展示规则**，选择客户端目录，添加公告后保存全部规则。
游戏自动载入已保存的配置，不需要 Manager 常驻。将共享规则随服主提供的客户端包或更新分发给玩家。
也可以从面板导出已保存的公告配置包，其他客户端关闭游戏后，通过 Manager 的“导入配置包”安装。
配置包包含 Mod、规则和登录页，保留各客户端自己的展示计数。

登录位置在原版公告抽屉内使用 Windows 网页控件，保留原来的打开、关闭按钮；
游戏内使用原版左侧 GM 文字面板，保留原生动画与翻页。
可编辑标题和纯文字正文，登录页会转义正文。手工公告规则默认留空，动态资讯默认开启，两个功能可以分别管理。

## 动态资讯

同一面板可以选择每日新闻、科技资讯、Epic 有效限免和历史趣闻，预览缓存，设置来源、星期、时段、
游戏事件与展示限制，并手动刷新。同优先级时先展示手工公告。

登录简报默认包含三条新闻和两条科技资讯，每日、每次启动最多一份，展示25秒。
游戏内资讯默认关闭，游戏内触发事件全部取消勾选。新增手工公告也默认只选登录位置，每日、每次启动最多一次。
需要游戏内提示时，请主动启用并选择触发事件；启用后可设置每日最多五条、每次启动最多三条，
间隔至少十分钟，每个原生文字页展示十秒。默认保留“仅在大厅”的范围限制，可在面板取消；
保持勾选时，房间或战斗事件触发的资讯也会等待回到大厅。投放记录按本客户端保存，不是服务端按账号统计。

缓存需要更新时，客户端在后台发起有限时请求，登录和渲染线程不等待网络。
默认每六小时刷新一次，内容最长有效48小时；来源失败时使用近期缓存，过期后停止展示。
新闻保留实际日期和来源，不把昨日简报标为今日新闻。历史内容核对日期；限免以明确的起止时间判断，
排除尚未开始、已经结束及永久免费的游戏，不直接信任上游的 `is_free_now` 标记。
限免的实际领取截止时间与缓存到期时间分别保存。

默认按顺序使用两个免密钥的 [60s API](https://github.com/vikiboss/60s) 社区实例，公共实例不保证持续可用。
可从项目的[公共实例列表](https://docs.60s-api.viki.moe/7306811m0)选择兼容来源，也可以使用自建接口。
上游主站用于开发调试，不作为默认正式来源。来源须为不含账号和查询令牌的 HTTPS 地址；
本机接口也支持字面回环地址的 HTTP。接口响应有大小、结构和超时限制，正文作为纯文字转义后显示，
不会发送账号、机库或对局数据。

可选的“公告资讯更新”服务使用 Manager 的统一后台服务管理，在 Manager 开启时更新选中客户端的缓存；
关闭 Manager 后，客户端自身仍可后台获取。切换客户端目录前先停止该服务。面板显示来源状态、
最近尝试时间和可用内容预览。

每条公告可同时限定日期范围、星期、每天时段、间隔和次数，并选择一个或多个触发事件：
进入对应公告位置、时段内定时、登录成功、进入大厅、进入房间、战斗开始、战斗结束。
触发事件之间是“任一满足”，其余限制必须全部满足。登录位置使用“进入对应公告位置”和“定时”；
其余游戏事件作用于游戏内位置。时段包含开始时间，不包含结束时间；开始和结束相同表示全天。
跨午夜时段按开始日的日期和星期计算。日期使用面板中设置的 UTC 时区偏移。

优先级越高越先显示，同优先级按编辑顺序。正在显示的原生公告先完成；事件公告在面板忙时等待，
若等待期间离开允许时段则取消。间隔限制同一条公告两次展示的最短时间。游戏内时长按每页计算，
登录公告按整条计算；触发时段结束时，已经显示的原生页会完成本次展示。

可分别设置每次启动、每日、累计的次数上限，**0 表示不限**。同一条规则在两个位置共享次数，
每日和累计计数保存在本客户端，不是服务端按账号统计。修改正文保留次数；复制公告会生成独立标识，
拥有独立计数。登录公告读取原生浏览器中的真实可见正文后计数；游戏内由原生 GM 渲染器消费公告后计数。
次数限制统计自动投放；玩家也可以通过原生登录按钮重读当前公告。服务端即时 GM 广播沿用原生广播队列。

共享配置位于 Mod 目录的 `rules.json`、`runtime.ini`、`news-settings.json`、`news.ini` 和手工公告的 `pages`。
框架更新保留已有配置；`sdgo/local-state` 中的本地计数、下载缓存和动态页面不会进入公告配置导出包。
保存时检查版本，另一处已修改会拒绝覆盖。新规则影响后续显示决定，已经显示的公告完成原生动画。
符号校验不支持的客户端不会启用该 Mod。登录公告需要 Windows 的 ATL/WebBrowser 组件，
游戏内文字使用独立入口。首次安装或更新 Mod 后重新打开客户端；之后保存的规则自动载入。

默认时区为中国标准时间（北京时间，UTC+8，偏移分钟 480）。
