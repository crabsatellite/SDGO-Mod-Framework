# 公告与展示规则

打开 **SDGO Mod Manager → 服主工具 → 公告与展示规则**，选择客户端目录，添加公告后保存全部规则。
游戏自动载入已保存的配置，不需要 Manager 常驻。将共享规则随服主提供的客户端包或更新分发给玩家。
也可以从面板导出已保存的公告配置包，其他客户端关闭游戏后，通过 Manager 的“导入配置包”安装。
配置包包含 Mod、规则和登录页，保留各客户端自己的展示计数。

登录位置在原版公告抽屉内使用 Windows 网页控件，保留原来的打开、关闭按钮；
游戏内使用原版左侧 GM 文字面板，保留原生动画与翻页。
可编辑标题和纯文字正文，登录页会转义正文。默认规则为空时保留原版公告行为。

每条公告可同时限定日期范围、星期、每天时段、间隔和次数，并选择一个或多个触发事件：
进入对应公告位置、时段内定时、登录成功、进入大厅、进入房间、战斗开始、战斗结束。
触发事件之间是“任一满足”，其余限制必须全部满足。登录位置使用“进入对应公告位置”和“定时”；
其余游戏事件作用于游戏内位置。时段包含开始时间，不包含结束时间；开始和结束相同表示全天。
跨午夜时段按开始日的日期和星期计算。日期使用面板中设置的 UTC 时区偏移。

优先级越高越先显示，同优先级按编辑顺序。正在显示的原生公告先完成；事件公告在面板忙时等待，
若等待期间离开允许时段则取消。间隔限制同一条公告两次展示的最短时间。游戏内时长按每页计算，
登录公告按整条计算；触发时段结束时，已经显示的原生页会完成本次展示。

可分别设置每次启动、每日、累计的次数上限，**0 表示不限**。同一条规则在两个位置共享次数，
每日和累计计数保存在本客户端，不是服务端按账号统计。修改正文保留次数；复制公告会生成独立标识，
拥有独立计数。登录公告读取原生浏览器中的真实可见正文后计数；游戏内由原生 GM 渲染器消费公告后计数。
次数限制统计自动投放；玩家也可以通过原生登录按钮重读当前公告。服务端即时 GM 广播沿用原生广播队列。

共享配置位于 Mod 目录的 `rules.json`、`runtime.ini` 和生成的 `pages`。
框架更新保留已有规则文件；`sdgo/local-state` 中的本地计数不应分发。
保存时检查版本，另一处已修改会拒绝覆盖。新规则影响后续显示决定，已经显示的公告完成原生动画。
符号校验不支持的客户端不会启用该 Mod。登录公告需要 Windows 的 ATL/WebBrowser 组件，
游戏内文字使用独立入口。首次安装或更新 Mod 后重新打开客户端；之后保存的规则自动载入。
