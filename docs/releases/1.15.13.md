## 中文

修复启动前校验已接受请求，但系统 HTTP 代理拦截本机 Manager 通信而无法继续启动游戏的问题。

- 启动进度和 Manager 会话发现直连回环地址，程序与内容下载继续使用既有网络配置。
- 保留每次启动的连接、提交、更新阶段及错误诊断，后台线程异常可重试或取消。
- 原始启动命令行保持不变，包括引号和末尾空格。

## English

Fixes accepted startup requests failing to continue when an HTTP proxy intercepts communication with the local Manager.

- Startup progress and Manager session discovery connect directly over loopback; programme and content downloads retain their network configuration.
- Per-request diagnostics retain connection, submission and update phases and errors. Background worker failures remain available for Retry or Cancel.
- The original command line, including quotes and trailing spaces, is preserved.
