## 中文

导入任务使用游戏原生的机体图片横幅，并修正自定义 NPC 攻击定义与阶段衔接。

- `map_catalog`：NPC 可声明机体图片横幅，复用原生展示、动画和分辨率适配；可引用已有 SPR，或提供机体图片并声明裁剪区域，去掉白边、保留原图比例。
- 地图与副官资源复用已经加载的目录资源服务；未启用扭蛋目录时，也能与机体目录同时加载，避免争抢同一个原生资源挂钩。
- 修正任务 NPC 的攻击倍率只修改客户端武器记录的问题。现在成对生成客户端与服务端的任务机体、武器和击破目标编号，保留原有 AI 脚本、动作与设计图掉落来源。
- 新增 `map_catalog_server`：只为内容包声明的导入任务取消普通阶段的固定等待；过场动画与最终结算继续走原生流程。
- 刷怪时间从过场结束后的活动阶段计时，不再额外等待一次过场时长；保留 `at: 0` 的首波时间。
- 示例任务在黑色三连星后先击破指挥官，再肃清守军，移除自制文字横幅。
- 任务新语义使用协议 v2，配套服务端计划使用 `/2`，旧 Manager 会明确拒绝；已有 v1 任务和旧计划仍可读取。

已有导入任务需要用新版 Manager 重新编译、应用配套服务端计划并重启 World/Battle，然后再发布匹配的客户端内容。玩家配置、账号、库存和货币不属于这些定义更新。

## English

Imported missions use the game's native unit illustration strip and correct custom NPC attack definitions and phase transitions.

- `map_catalog`: NPCs can declare a unit illustration strip using the original presentation, animation and resolution scaling. Reference an existing SPR or provide unit artwork with a crop rectangle to remove white margins and retain its aspect.
- Map and operator resources reuse the active catalogue resource service. They can compose with the unit catalogue when the capsule catalogue is disabled, without competing for the native resource hook.
- Fixes NPC attack factors that previously changed only client weapon records. Client and server NPC units, weapons and kill-goal unit IDs are now generated together, retaining the existing AI scripts, animations and blueprint sources.
- Adds `map_catalog_server`: removes the fixed ordinary transition delay only for declared imported missions. Cutscenes and final settlement retain their native flow.
- Wave times start with active play after the cutscene, without waiting for its duration twice; the first wave retains `at: 0`.
- After the Tri-Stars, the example mission targets commanders before cleaning up the remaining force and removes custom text banners.
- New mission semantics require protocol v2 and server plans use `/2`, so older Managers reject them explicitly. Existing v1 missions and legacy plans remain readable.

Recompile existing imports with the updated Manager, apply the paired server plan and restart World/Battle before publishing matching client content. These definition changes do not include player settings, accounts, inventories or currencies.
