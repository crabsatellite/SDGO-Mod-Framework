## 中文

修复任务 AI 僚机因缺少原生聊天符号而没有加载的问题。任务房间选择 Hard 或使用 `!ai hard` 后，客户端可以正常生成服务端安排的僚机。

- `mission_ai` 现在随包提供自己的聊天符号声明，不依赖其他 AI 模组的私有符号表。
- 发布检查逐个核对模组实际可见的符号；其他模组的声明不能掩盖缺失文件。
- AI 难度、生命额度、复活、王牌概率和玩家数据保持原有规则。更新客户端后需重新启动游戏。

## English

Fixes mission wingmen failing to load because their native chat symbols were missing. Choosing Hard in a mission room or using `!ai hard` can now create the wingmen assigned by the server.

- `mission_ai` ships its own chat symbol declarations and does not depend on another AI Mod's private symbol table.
- Release checks validate each Mod's actual symbol scope; declarations from another Mod cannot hide missing files.
- Existing difficulty, life allowances, respawns, Ace chances and player data are preserved. Restart the game after updating the client.
