## 中文

OC 六维强化页面的显示修正（客户端 Mod OC 六维强化 0.6.3）。

- 维度图改为原版 OC 的画法：深绿色是机体自身的属性，浅绿色是普通点增加的部分，黄色只显示 Over 点增加的部分；各项按客户端属性图表的范围折算（例如耐久力 4000–23800），打开时从中心展开。原先固定照亮左边一角的光影不再显示。
- 维度图显示在工厂的机体模型前面，大型机体（例如带翅膀的机体）不再挡住图形；确认框和挑战窗仍在图形之上。
- 点击「终极强化」时，不再先闪出「经验值转换」页面和标签；从其他标签切回时，标题正确显示「终极强化」。
- 刚进工厂时停在「强化部件」页，「G改 2.0」「G改 1.0」切换按钮直接显示，不必先切换标签。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启客户端；服务端 Mod 不变。

## English

Display fixes for the Over-custom page (client Mod Over-custom stats 0.6.3).

- The chart is drawn the way the original OC client drew it: dark green for the unit's own stats, light green for what the normal points add, and yellow only for what the Over points add; each stat is scaled by the client's stat graph range (for example HP 4000–23800), and the chart grows from its centre when it opens. The light sheet that lit a fixed corner on the left is no longer shown.
- The chart stands in front of the factory's unit model, so large units (for example winged ones) no longer cover it; the confirmation and challenge windows still stand over the chart.
- Clicking 终极强化 no longer flashes the 经验值转换 page and tab first, and switching back from another tab shows the 终极强化 title.
- When the factory opens on the 强化部件 page, the 「G改 2.0」 and 「G改 1.0」 switch shows right away, without switching tabs first.
- Update through SDGO Mod Manager or the server owner's client package or update, then restart the client; the server Mods are unchanged.
