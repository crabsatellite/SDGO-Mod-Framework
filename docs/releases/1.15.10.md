## 中文

修复每局随机机体在战后返回时，切换库存机体可能误报“技能零件已耗尽”的问题。

- 客户端按完整库存机体身份核对技能零件变化，清理跨机体的过期比较。
- 同一库存机体真正耗尽技能零件时，继续显示原生提醒。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启游戏客户端。

## English

Fixes false skill-part exhaustion notices when returning from a random-loadout battle to another inventory unit.

- The client checks the complete inventory instance identity before comparing equipped skill parts.
- Genuine skill-part removal on the same inventory instance retains the native notice.
- Update through SDGO Mod Manager or the server owner's client package or update, then restart the game client.
