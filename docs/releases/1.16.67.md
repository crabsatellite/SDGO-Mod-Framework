# SDGO Mod Manager 1.16.67

## 中文

- 修复 Grid 和 Tag 战舰房间更新随机编队时，战舰预览误加载机体模型导致的闪退。房间继续显示原有战舰，战斗使用随机选出的完整机体编队。

## English

- Fixes a crash when a Grid or Tag battleship room tried to load a randomized mobile-suit model as its battleship preview. The room keeps the original battleship preview, and the match uses the full randomized deck.
