## 中文

修正导入任务在配置 NPC 攻击倍率后，默认房间名、任务目录名称和任务说明标题被武器字段名替换的问题。编译器现在始终保留任务文件中填写的名称，同时保持客户端与服务端的武器配对。

已有受影响内容需使用新版 Manager 重新编译并发布客户端内容。仅这项名称修复不改变服务端定义、NPC 伤害、阶段目标或过场；服务端计划无差异时无需重新应用或重启服务端。玩家通过服主提供的客户端包或更新取得修正。

## English

Fixes imported missions whose default room name, catalogue name and objective title were replaced by a weapon field name after configuring NPC attack multipliers. The compiler now retains the name authored in the mission file while preserving paired client/server weapon definitions.

Recompile affected content with the updated Manager and publish the client content. This title fix does not change server definitions, NPC damage, phase goals or cutscenes. An unchanged server plan needs no reapplication or server restart. Players receive the correction through the server owner's client package or update.
