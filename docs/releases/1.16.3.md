## 中文

机库「一键整理」和「重复兑换」改为当场生效，客户端立即刷新，不再需要退出重新登录。

- 一键整理：服务器整理完成后，机体管理页当场显示新的顺序，出击机体保持不变。
- 重复兑换（GB）：服务器确认后，兑换掉的机体当场从页面消失，GB 余额同时更新。
- 服务器拒绝请求时机库保持不变，页面直接说明；只有无法确认服务器结果或刷新数据时，才提示重新登录查看。
- 刷新使用游戏原有的槽位分页请求和用户信息请求，从服务器读取实际结果，不在客户端自行推算。
- 需要客户端 Mod 机库管理 0.5.0；服务端机库通道无需重装。通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启客户端。
- 本版本同时包含 1.16.1 的全部改动。

## English

Hangar sort and duplicate exchange now take effect immediately; the client refreshes in place without a re-login.

- Sort: once the server has sorted, the unit-management page shows the new order right away and the active unit stays active.
- Duplicate exchange (GB): once the server confirms, the exchanged units leave the page and the GB balance updates at the same time.
- A refused request leaves the hangar unchanged and the page says so; only when the server's answer or the refreshed data cannot be confirmed does the page ask you to log in again.
- The refresh uses the game's own slot-page and user-info requests and shows what the server actually stored; nothing is inferred on the client.
- Requires client Mod Hangar manager 0.5.0; the server hangar adapter needs no reinstall. Update through SDGO Mod Manager or the server owner's client package or update, then restart the client.
- This release also includes everything in 1.16.1.
