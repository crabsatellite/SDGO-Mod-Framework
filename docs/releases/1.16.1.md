## 中文

1.16.1 系列把机体族导入升级为 Stable，并完善机体目录（机体目录 Mod 0.5.0）：

- 机体族导入（Manager「机体导入」面板、`unit_catalog`、`unit_catalog_server`）从 Beta 转为 Stable，只更新 Stable 的 Manager 也会安装这两个运行 Mod。它们安装后默认关闭，关闭时游戏不加载；服务端发布和玩家安装机体客户端包时才开启。
- 导入内容可以携带武器引用的特殊效果记录（客户端类型 12，与原版特殊效果表相同的 1559 字节格式）。导入武器引用的特殊效果既不在原版表中、也没有随内容携带时，客户端拒绝加载导入目录，不会等到战斗中效果触发时才闪退。
- 携带特殊效果记录的服主内容需要本版本的机体目录 Mod；服主更新内容时一并采用本版本。
- 内容文字归属索引只收录武器名称，不再把武器记录里的数值和特效路径当作受保护文字。
- Mod Manager 指南新增「游戏会加载哪些组件」，说明运行 Mod、Manager 服主工具和开发诊断的加载区别。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启客户端。

## English

The 1.16.1 series promotes unit family import to Stable and extends the unit catalog (unit catalog Mod 0.5.0):

- Unit family import (the Manager **机体导入** panel, `unit_catalog` and `unit_catalog_server`) moves from Beta to Stable, so a Stable-only Manager also installs both runtime Mods. They are installed switched off and the game does not load them until server publication or the player's unit client package turns them on.
- Imported content can carry the special-feature records its weapons name (client kind 12, the same 1559-byte layout as the stock special-feature tables). When an imported weapon names a special feature that is neither in the stock tables nor carried with the content, the client refuses to load the imported catalog instead of crashing when the feature triggers in battle.
- Server-owner content that carries special-feature records needs this version's unit catalog Mod; owners adopt this version together with such content.
- The content text ownership index records only weapon names and no longer treats numeric weapon data or effect paths as protected text.
- The Mod Manager guide gains "What the game loads", which separates runtime Mods, Manager owner tools and developer diagnostics.
- Update through SDGO Mod Manager or the server owner's client package or update, then restart the client.
