## 中文

地图与任务导入（Beta）：Bloom 修正、现代规格的地图素材与可下载的示例地图。

- 修正：导入地图在开启 Bloom（HDR）时整体发白。地图行中的 Bloom 亮度阈值此前被留成 0，现在与原版一致；已导入的地图请用新版 Manager 重新编译、安装客户端包。
- 地表层遮罩换算成每个顶点合计 255 的混合权重（与原版地图一致）；模型贴图最大 2048 像素，不透明贴图以 JPEG 保存，客户端包更小。
- 地图包的模型贴图和地表层贴图可以使用 JPEG；`.gltf` 模型可以共用包内的缓冲区和贴图文件。
- 任务可用 `area` 设置开局活动范围（开场过场开始时生效），阶段 `enter.area` 和区域切换 `rect` 改变活动范围；玩家被限制在当前范围内，与原版多区域任务相同。
- 任务可用 `presentation` 提供自己的任务列表图片（列表横幅、房间图标、房间海报、标题字、读取画面）。
- 「地图与任务导入」页新增「示例地图」：一键下载并登记《双谷要塞 · 奥德萨作战》（南谷对战场、山脊要塞闸门、北谷矿区基地与南端工厂区，附 6 阶段 PvE 任务），每个文件按 SHA-256 校验。文件同时位于仓库 `examples/maps/twin-valley-fortress`，可作为编写地图包的参考。
- 通过 SDGO Mod Manager 更新；客户端 Mod `map_catalog` 不变。

## English

Map and mission import (Beta): a Bloom fix, modern-budget map art and a downloadable example map.

- Fixed: imported maps washed out to white with Bloom (HDR) on. The map row's Bloom bright-pass threshold was left at 0 and now matches the shipped maps; compile and install the client package again with the new Manager for maps imported earlier.
- Terrain layer masks become per-vertex blend weights that sum to 255, as in the shipped maps; model textures may be up to 2048 pixels and opaque textures are stored as JPEG, which makes the client package smaller.
- Map packages may use JPEG for model and terrain layer textures; `.gltf` models may share buffer and texture files in the package.
- A mission can set its starting movable area with `area` (applied when the opening cutscene starts) and change it with a phase's `enter.area` or a sector's `rect`; players are kept inside the current area, as in the shipped multi-area missions.
- A mission can bring its own mission list artwork through `presentation` (list banner, room icon, room poster, title lettering, loading screen).
- The map and mission import page has a new **示例地图** (example maps) card: download and register *Twin Valley Fortress · Operation Odessa* (south valley arena, ridge fortress gate, north valley mining base and a south factory district, with a six-phase PvE mission) in one step, every file checked against its SHA-256. The files are also in the repository under `examples/maps/twin-valley-fortress` as a reference for writing map packages.
- Update through SDGO Mod Manager; the client Mod `map_catalog` is unchanged.
