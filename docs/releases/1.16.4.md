# SDGO Mod Manager 1.16.4

## 中文

保管库「一键领取」改为一次全收：确认一次后先读完当前页签的全部分页，再把所有奖品连续提交服务器，最后刷新一次列表，不再逐件领取、逐件刷新。服务器拒绝的奖品跳过并计数，结果栏一次说明；需要选择内容的礼包仍留给原生按钮。

机体一览的好友赠送信息只在确实由好友赠送的机体上显示。左侧机体画面下沿改用原生蓝色信息栏，显示赠送者和日期，「查看寄语」打开原生机体信息卡查看完整寄语；普通机体不再出现赠送入口。

- 需要客户端 Mod 保管库一键领取 0.2.0、好友机体赠送 0.1.9；服务端无需更改。通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启客户端。

## English

Storage **一键领取** now claims everything at once: after one confirmation it reads every page of the current tab, submits all rewards to the server back to back and reloads the list once, instead of claiming and reloading reward by reward. Rewards the server refuses are skipped and counted in one summary; choice gifts are still left for the native buttons.

Friend-gift information in the unit list only appears on units actually received as friend gifts. The left 3D view now shows a native blue strip with the sender and dates, and **查看寄语** opens the native unit information card with the full note; ordinary units no longer show a gift entry.

- Requires client Mods Storage claim all 0.2.0 and Friend owned-unit gifts 0.1.9; no server change. Update through SDGO Mod Manager or the server owner's client package or update, then restart the client.
