## 中文

地图与任务导入修正派生 NPC 的旧演出引用，并加入原生命名门板及实际炮击控制。

- `map_catalog` 只为任务包明确声明的有效台词启用机体横幅。新版编译器清除模板原关卡的可选演出引用，避免不存在的台词编号进入原生界面队列。
- 命名门板使用原生可破坏物件、碰撞、HP 与武器攻击；NPC 可以把门板作为真实目标开火，阶段成功后再开放通道。
- 显示名称与脚本内部标识分别保存，玩家看到可读名称。示例任务的保护阶段保持闸门关闭，钢坦克持续炮击，成功进入后续阶段才开门。
- 地图包 v2、任务 v3 与服务端计划 `/3` 承载新语义。旧任务和旧计划继续读取；旧编译器会拒绝新格式，不会把门板当作普通静态物件忽略功能。

命名门板新增配对的物件定义和地图放置行。服主需应用服务端计划、重启对应 World/Battle，并发布匹配的客户端内容；玩家安装内容不执行 SQL。模块继续保持可选、默认关闭。

## English

Map and mission import fixes inherited NPC presentation references and adds native named gates with real bombardment control.

- `map_catalog` enables unit illustration strips only for valid speech declared by the mission package. Compilation clears optional presentation references belonging to the template's original mission, keeping missing speech IDs out of the native UI queue.
- Named gates use the game's destroyable objects, collision, HP and weapon attacks. NPCs can fire at the actual gate target; a successful phase transition then opens the passage.
- Display names remain separate from internal script keys. In the example mission, the gate stays closed during protection, the Guntank bombards it, and the next successful phase opens it.
- Map package v2, mission v3 and server plan `/3` carry these semantics. Existing missions and plans remain readable; older compilers reject new formats instead of silently treating the gate as an ordinary static prop.

Named gates add paired object definitions and map placement rows. Owners apply the server plan, restart the affected World/Battle hosts and publish matching client content. Player content installation does not execute SQL. The feature remains optional and disabled by default.
