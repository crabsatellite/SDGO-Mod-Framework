# SDGO Mod Manager 1.16.60

## 中文

- 机体信息页用三栏显示 OC 六维图和两套部件。本人和其他玩家查看同一台机体时，必杀值随首帧显示，加点只改变对应轴。工厂显示剩余普通点和 OC 点，切回 G改 2.0 时恢复分类图标。
- 工厂支持原生强化道具格和 EX 技能选择。房主和加入者都能在房名下方看到当前体系，开启随机队伍后两个提示可同时显示。战斗根据房间体系选择对应的强化槽。

- 原生无边框显示的设置页新增本地图片高清预览。选择自己的 PNG，可生成 2 倍或 3 倍的图片、对比本地 AI 成图并保存 PNG。预览保留原图的透明度。

## English

- Unit inspection shows the OC radar and both parts sets in three columns. Owners and visitors see the special value on the first chart, and each allocation changes its own axis. The factory shows the remaining normal and OC balances and restores category icons when switching back to G改 2.0.
- The factory supports native enhancement item slots and EX ability selection. Hosts and guests see the current system below the room name alongside the random-team notice. Battles select the enhancement slots for the room’s system.

- The native borderless display settings now include a local image preview. Resize your own PNG to 2× or 3×, compare it with output from a local AI tool, and save a PNG. The preview retains the source transparency.
