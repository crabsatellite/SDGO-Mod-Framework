# SDGO Mod Manager 1.16.0

## 中文

新增「原生界面中文汉化」：自定义扭蛋机配置窗的原版泰文按钮使用原生字体显示中文，并补充受支持布局和较长系统提示。保留 EXIT、SEARCH 等简单英语，不修改原版图片。

补充原客户端机体名称与一条遗漏的机体长说明。机库、资料和已核实预览入口按机体身份处理显示名，保留已有中文及原生格式。OC 页面复用名称汉化并保留原有中文提示。

自定义机体、技能、武器和说明继续随内容包分发。公共汉化通过内容归属接口跳过内容包记录及同文词条，归属不能确认时保留原文。

## English

Adds Chinese native interface text: the original Thai buttons in the custom capsule configuration window use native Chinese typography, with reviewed layout phrases and longer system messages. Simple English such as EXIT and SEARCH remains, and original images are untouched.

Adds original-client unit-name aliases and one missing long unit description. Verified hangar, information and preview callers translate names using unit identity while preserving existing Chinese and native formatting. OC pages share name localization and retain existing Chinese messages.

Custom units, skills, weapons and descriptions remain content-package data. Public localization uses the content ownership interface to bypass package records and matching text, preserving source text when ownership cannot be established.
