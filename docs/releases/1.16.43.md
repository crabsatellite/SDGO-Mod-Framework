# SDGO Mod Manager 1.16.43

## 中文

- 机体外观以 Beta 提供 RGB 涂装与自由贴花：在原生涂装页调整六区域颜色，在纹章页放置、旋转和缩放已有贴纸，预览后由 World 确认保存，并同步到房间与战斗中的具体机体。
- Manager 分别管理两项开关，升级保留旧颜色、位置与启用设置，并备份停用旧组件。RGB 控件接管完整鼠标操作，防止误拖下层道具；房间异步模型和备用变形模型保留正确机体身份。
- 客户端 0.1.2 修复反射装甲上的贴花在对战中退回原生位置：按实际覆盖的材质判断透明度，保留隐身、淡出与特殊混合处理；RGB 道具输入钩子兼容 OC，World 仍兼容 0.1.0。

商城大目录按实际条目与文件预算处理，新增商品查找合法空闲编号，保护其他原生记录和既有商品身份。

- 商品列表分页，搜索覆盖整个目录，继续在 Manager 编辑、保存和应用。
- 服务器应用、客户端显示和玩家更新导出支持配套大目录，保留原生分页、购买、赠送、价格和发货逻辑。
- 编号分配排除原生、隐藏、已删除、其他目录及所选客户端的预留身份；显示记录跳过共享表占用，空间耗尽时拒绝覆盖。
- 大批量应用复用受归属保护的事务，兼容数据库排序规则差异；扩展目录检查旧版程序，避免配套不完整。
- 继续内置五个可编辑预设，具体物品和价格沿用目标服现货，不包含服主私有内容。

## English

- Unit appearance introduces RGB paint and free stickers in Beta: edit six color regions on the native paint page, place, rotate and resize equipped stickers on the emblem page, preview and save with World acknowledgement, and synchronize each owned unit's appearance in rooms and battles.
- Manager provides independent switches, preserves legacy colors, placements and enablement, and backs up retired components. RGB controls own complete mouse gestures to prevent covered inventory drags; asynchronous room models and dormant transformation models retain the correct unit identity.
- Client 0.1.2 keeps saved sticker positions on reflective armor in battle, checks opacity only on covered materials, and preserves native handling of hidden, fading and special-blend surfaces. RGB inventory input hooks coexist with OC; World 0.1.0 remains compatible.

Large shop catalogs use actual entries and file budgets. New offers search legal free identities while preserving existing products and other native records.

- Paginated lists retain whole-catalog search, editing, saving and explicit application.
- Matching server, display and player-update validation retain native paging, purchases, gifting, prices and delivery.
- Allocation excludes native, hidden, retired, other-catalog and selected-client reservations. Shared display keys skip occupied records and refuse overwrite on exhaustion.
- Large applications reuse an ownership-guarded transaction with destination-compatible collation. Expanded catalogs check legacy programme versions before application or export.
- Five editable defaults remain built in, resolving against destination stock without private owner content.
