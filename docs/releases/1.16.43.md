# SDGO Mod Manager 1.16.43

## 中文

商城大目录按实际条目与文件预算处理，新增商品查找合法空闲编号，保护其他原生记录和既有商品身份。

- 商品列表分页，搜索覆盖整个目录，继续在 Manager 编辑、保存和应用。
- 服务器应用、客户端显示和玩家更新导出支持配套大目录，保留原生分页、购买、赠送、价格和发货逻辑。
- 编号分配排除原生、隐藏、已删除、其他目录及所选客户端的预留身份；显示记录跳过共享表占用，空间耗尽时拒绝覆盖。
- 大批量应用复用受归属保护的事务，兼容数据库排序规则差异；扩展目录检查旧版程序，避免配套不完整。
- 继续内置五个可编辑预设，具体物品和价格沿用目标服现货，不包含服主私有内容。

## English

Large shop catalogs use actual entries and file budgets. New offers search legal free identities while preserving existing products and other native records.

- Paginated lists retain whole-catalog search, editing, saving and explicit application.
- Matching server, display and player-update validation retain native paging, purchases, gifting, prices and delivery.
- Allocation excludes native, hidden, retired, other-catalog and selected-client reservations. Shared display keys skip occupied records and refuse overwrite on exhaustion.
- Large applications reuse an ownership-guarded transaction with destination-compatible collation. Expanded catalogs check legacy programme versions before application or export.
- Five editable defaults remain built in, resolving against destination stock without private owner content.
