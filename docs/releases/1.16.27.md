## 中文

修正命名闸门与阶段过场的执行顺序。

- 保护完成后，门板状态先应用，再开始下一段原生过场，避免门板挡住登场镜头。
- 同一过场被多个阶段复用时，各阶段的门状态分别绑定，不影响开场或其他阶段。
- 不带过场的阶段继续在阶段开始时应用门状态。已有任务需重新编译并发布匹配的客户端包与服务端计划。

## English

Fix the ordering of named gate changes and entry cinematics.

- A successful protection phase applies the gate state before the next native cinematic, keeping the door out of the arrival camera path.
- Reused cinematics retain separate object-state bindings for each phase without changing their opening or other uses.
- Phases without a cinematic still apply object changes at phase entry. Rebuild existing missions and publish the matching client package and server plan.
