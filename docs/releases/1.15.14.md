## 中文

修复战斗 AI 在近战必杀结束后可能一直停留在必杀状态的问题。

- 正确识别原生近战必杀结束通知，让服务器确认的零伤害必杀进入原有收尾流程。
- SP 独立更新不再清除本次必杀的动作确认；服务器结果晚于本地动画时仍可正常收尾。
- 保留原生伤害、动作身份和受击者捕获检查。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启游戏客户端。

### OC 六维强化与按房间选择的强化体系进入 Stable

- 「终极强化」（OC）页面、原版「强化部件」页面上的「G改 2.0 / G改 1.0」切换、建房窗口的「体系」行、房间列表与房内的体系标记，以及工厂页面的中文标签，现在随 Stable 更新安装。
- 修复：战斗载入期间原生房间数据变化时，客户端可能把 OC 房间误认作 G改 2.0 房间，漏加 OC 推进力和机动力。客户端现在在待机室确定房间的体系，载入和战斗期间保持不变。
- 同一客户端连续进入 OC、G改 1.0、G改 2.0 房间各打一场的原生 GameTest，现在作为发布前检查运行。
- 需要客户端 Mod 0.6.1、World 服务端 Mod 0.5.0、对战服务端 Mod 0.3.1。服务端在 `room` 模式下才按房间选择体系；G改 1.0 还需要服主提供规则文件。服务端 Mod 的改动需要重启 World 和对战服务端。

## English

Fixes Battle AI sometimes remaining in its melee special state after the attack ends.

- Recognizes the native melee completion notification so server-confirmed zero-damage specials can use the original finalizer.
- Independent SP updates preserve the action acknowledgement, including server results received after the local animation ends.
- Retains native damage, action identity and victim capture checks.
- Update through SDGO Mod Manager or the server owner's client package or update, then restart the game client.

### Over-custom and per-room enhancement systems move to Stable

- The 终极强化 (OC) page, the 「G改 2.0 / G改 1.0」 switch on the original 强化部件 page, the create window's 体系 row, the system marks in the room list and in the room, and the Chinese factory labels now install with Stable updates.
- Fix: when the native room data changed while the battle was loading, the client could treat an OC room as a G改 2.0 room and leave out the OC speed and agility gains. The client now settles the room's system in the waiting room and keeps it through loading and battle.
- A native GameTest that plays an OC, a G改 1.0 and a G改 2.0 room back to back in one client now runs as a pre-release check.
- Requires client Mod 0.6.1, World Mod 0.5.0 and Battle Mod 0.3.1. The server chooses systems per room only in `room` mode, and G改 1.0 also needs the owner's rule file. Server Mod changes need a World and Battle server restart.
