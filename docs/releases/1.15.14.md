## 中文

修复战斗 AI 在近战必杀结束后可能一直停留在必杀状态的问题。

- 正确识别原生近战必杀结束通知，让服务器确认的零伤害必杀进入原有收尾流程。
- SP 独立更新不再清除本次必杀的动作确认；服务器结果晚于本地动画时仍可正常收尾。
- 保留原生伤害、动作身份和受击者捕获检查。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启游戏客户端。

## English

Fixes Battle AI sometimes remaining in its melee special state after the attack ends.

- Recognizes the native melee completion notification so server-confirmed zero-damage specials can use the original finalizer.
- Independent SP updates preserve the action acknowledgement, including server results received after the local animation ends.
- Retains native damage, action identity and victim capture checks.
- Update through SDGO Mod Manager or the server owner's client package or update, then restart the game client.
