# SDGO Mod Manager 1.16.10

## 中文

保管库「一键领取」改为一次全收：确认一次后逐页连续领取当前页签的全部奖品，每件之间不再等待、不再刷新列表，也不会弹出空白提示框。服务器拒绝的奖品跳过并计数；进度和结果直接显示在「一键领取」按钮上，不再在窗口边缘另加文字；需要选择内容的礼包仍留给原生按钮。

机体一览的好友赠送信息只在确实由好友赠送的机体上显示：左侧机体画面左下角出现与「BR RANK」同风格的文字角标，显示赠送者和日期，右下角「查看寄语 >」打开原生机体信息卡查看完整寄语；普通机体不再出现赠送入口。保管库的「机体赠礼」入口改为整体数量行右侧的文字链接，不再压在窗口标题图案上。

服务端 Mod 好友机体赠送 0.1.3 修正：查询普通机体的赠送来源时回答“不是赠礼”，不再误报数据库不可用。客户端 0.1.9 也兼容旧服务端。

- 需要客户端 Mod 保管库一键领取 0.2.0、好友机体赠送 0.1.9；服务端好友机体赠送 0.1.3 为可选更新。通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启客户端。

## English

Storage **一键领取** now claims everything in one go: after one confirmation it claims every reward of the current tab page by page and back to back, without the pause and list reload between rewards and without empty message boxes. Rewards the server refuses are skipped and counted; progress and the result appear on the 一键领取 button itself instead of an extra text line at the dialog edge; choice gifts are still left for the native buttons.

Friend-gift information in the unit list only appears on units actually received as friend gifts: the left 3D view shows a caption in the style of its BR RANK label with the sender and date, and **查看寄语 >** opens the native unit information card with the full note; ordinary units no longer show a gift entry. The storage 机体赠礼 entry is now a text link at the right end of the item count line instead of a button over the dialog header art.

Server Mod Friend unit gifting 0.1.3 answers a provenance query for an ordinary unit with "not a gift" instead of reporting the database as unavailable. Client 0.1.9 also handles older servers.

- Requires client Mods Storage claim all 0.2.0 and Friend owned-unit gifts 0.1.9; the server Mod Friend unit gifting 0.1.3 is an optional update. Update through SDGO Mod Manager or the server owner's client package or update, then restart the client.
