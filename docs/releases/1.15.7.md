## 中文

1.15.7 系列完善服主配置驱动的安装与启动流程：

- 官方框架与公共 Mod、本服可分发补丁、共享配置及内容分别维护，由一个服主配置入口组合安装。
- 启动游戏前完整校验所需程序和内容，Manager 自更新后继续原来的启动请求。
- 修复已运行 Manager 启动原版客户端时的权限上下文，以及短暂会话错误后启动进度无法正确结束的问题。
- 修复内容摘要校验，并在只导入一个配置地址时保留发布者声明的备用源。
- 各 Mod 的 Stable／Beta 通道分别管理；通用程序包不携带服主私有内容、凭据或仅本机插件。

具体程序与可用模块以本次下载包的清单及各功能指南为准。

## English

The 1.15.7 series completes profile-driven installation and launch:

- Official programmes, distributable owner patches, shared settings and content remain separate and compose through one owner profile.
- Required files are verified before game launch; Manager self-update continues the original launch request.
- Fixes the original host's privilege context when started by an existing Manager, and startup progress completion after transient session errors.
- Fixes content fingerprint verification and preserves publisher-declared backup sources during single-address import.
- Individual Mod channels remain independent. Generic programme packages exclude private owner content, credentials and local-only addons.

The downloaded package manifest and feature guides determine its actual modules and channels.
