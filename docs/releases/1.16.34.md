## 中文

机体导入加入两套公开演示配方，并支持技能触发的三阶段成长。

- 「薪火计划·继承者」定位为4点AR成长机，以吉姆、高达和ν高达外观表现三个阶段。耐久85%与45%以下且对应原生技能生效时请求升级；各阶段统一A档计分，升级不恢复耐久。终态步枪、基础机动和技能增益经过限制，保留前期与低血量的取舍。
- 「余烬装甲试验机」以原生装甲／脱甲模型演示BR单向爆甲，在低耐久时切换为机动步枪战。
- Manager 默认登记配套的客户端与服务端数据，保留已有机体和其他形态图；可以关闭自动登记。再次打开 Manager 时会只读核对已安装数据，避免重复要求停服。
- 三阶段机体保留原生变形资格与请求流程，并补齐额外模型在退场和重生后的资源清理。
- 机体制作面板、原生技能说明和首次导入已安装框架的客户端得到修正。相同版本程序可复用，已有设置与内容所有权保持独立。

程序包只提供通用配方与工具，模型、动作和原始图片从服主的兼容客户端生成。演示预设不创建商品、扭蛋槽位或玩家库存发放；获取方式由服主配置。机体与技能导入指南提供配套说明。

## English

Unit import adds two public demo recipes and native skill-triggered three-stage progression.

- **Kindling Inheritor** is a four-point AR growth unit using GM, Gundam and ν Gundam appearances. Upgrades require the corresponding native skill and HP at or below 85% and 45%. All stages retain A-tier scoring and never restore HP. Its final rifle, base mobility and skill bonuses retain a tradeoff between early weakness and low-HP power.
- **Ember Armor Testbed** uses the original armored and unarmored models for a BR one-way purge, trading armor for mobile rifle combat at low HP.
- Manager registers paired client/server data by default while preserving existing units and other form graphs. Registration can be disabled. Manager restarts verify installed data read-only instead of repeatedly requiring maintenance.
- Three-stage units retain native transformation eligibility and requests, with explicit cleanup of the additional model after battle or respawn.
- The unit editor, native skill descriptions and first content installation into an existing Framework client are corrected. Matching programmes are reused while settings and content ownership remain independent.

The programme includes generic recipes and tools. Models, animations and original images are prepared from the owner's compatible client. Demo registration creates no shop products, gacha slots or inventory grants; owners configure acquisition separately. The unit and skill import guides describe the workflow.
