# SDGO Mod Manager 1.16.62

## 中文

- 新机体包在导入、编译和批量应用前检查显示文本结束符，给出记录编号与字段位置，避免安装后才影响普通商品汉化。保留作者原始字节，不自动截短名称。
- Manager 的商城汉化与机体导入设置增加「检查汉化数据」，只读检查主目录、预设目录、词典和汉化开关，区分静态数据问题与尚未验证的运行状态。
- 旧内容出现归属索引错误时，日志明确记录 kind、id、offset、capacity 和修正入口；注册兼容及自定义名称保护保持不变。
- 修复网络模组遗留空端口使其他 Mod 开关报整数转换异常的问题；依赖计算使用声明默认值，不改写网络配置。
- 补充中英文排查步骤、文本字段契约及通用汉化词条示例。

## English

- Validate display-text terminators before unit import, compilation and batch apply. Errors identify the record and field; source bytes are preserved without automatic name truncation.
- Add **检查汉化数据** (Check localization data) to Manager's localization and unit-import settings. Read-only checks cover both catalog scopes, dictionary entries and translation switches; static results remain distinct from runtime activation.
- Legacy ownership-index errors now identify the exact kind, ID, offset and capacity with a repair route. Existing registration behavior and author-name protection are retained.
- Fix blank legacy network ports breaking unrelated Mod switches. Dependency calculations use declared defaults without rewriting network configuration.
- Document diagnosis, bounded text fields and a neutral translation example in both languages.
