## 中文

- 新增独立的新手保护服务端模组：在 Manager 按玩家名字选择本服名单，生命和普通武器伤害默认各两倍，可分别调整。任务和对战均适用，必杀、生命条数、库存和机体定义保持原规则。公开包默认关闭、名单为空；本服名单只保存于服务端，修改后重启对应 Battle 服务。
- 普通活动扭蛋模板可配置 S 级合计频率，并展示最终编译出的单项频率；保留原生 10000 格抽取序列与全部奖品，不改变玩家的抽取进度。未设置时沿用原规则，99 代币高阶模板独立保留。
- 副官掉落编辑器显示数量的数学期望，便于把同一物品的多条概率与数量区间配置为常规、惊喜和大奖档。沿用原生副官触发条件及现有掉落规则，无需额外掉落模组。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版。玩家共享配置和素材由服主配置档单独分发。

## English

- Added an independent newcomer-protection server Mod. Select players by name in Manager and configure health and ordinary weapon damage separately, both defaulting to 2×. Protection works in missions and PvP while special attacks, life counts, inventories and unit definitions retain their native rules. Public defaults are disabled with an empty roster; owner rosters stay on the server. Restart the relevant Battle service after editing.
- Ordinary activity presets can configure aggregate S-grade frequency and preview the final individual frequencies. Native 10,000-entry sequences, reward identities and player draw progress are preserved. Unset preferences retain existing behavior, and the premium 99-token preset remains separate.
- The operator drop editor shows expected quantities, making existing weighted quantity ranges easier to balance into ordinary, surprise and jackpot outcomes. Native trigger conditions and the existing drop mechanism are retained.
- Update through SDGO Mod Manager or the server owner's client package or update. Shared configuration and assets remain a separate owner-profile distribution.
