## 中文

OC 六维强化与按房间选择的强化体系（OC、G改 1.0、G改 2.0）进入 Stable 通道。

- 「终极强化」（OC）页面、原版「强化部件」页面上的「G改 2.0 / G改 1.0」切换、建房窗口的「体系」行、房间列表与房内的体系标记，以及工厂页面的中文标签，现在随 Stable 更新安装。
- 修复：战斗载入期间原生房间数据变化时，客户端可能把 OC 房间误认作 G改 2.0 房间，漏加 OC 推进力和机动力。客户端现在在待机室确定房间的体系，载入和战斗期间保持不变。
- 同一客户端连续进入 OC、G改 1.0、G改 2.0 房间各打一场的原生 GameTest，现在作为发布前检查运行。
- 需要客户端 Mod 0.6.1、World 服务端 Mod 0.5.0、对战服务端 Mod 0.3.1。服务端在 `room` 模式下才按房间选择体系；G改 1.0 还需要服主提供规则文件。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启游戏客户端。服务端 Mod 的改动需要重启 World 和对战服务端。

## English

Over-custom six-stat enhancement and the per-room enhancement systems (OC, G改 1.0, G改 2.0) move to the Stable channel.

- The 终极强化 (OC) page, the 「G改 2.0 / G改 1.0」 switch on the original 强化部件 page, the create window's 体系 row, the system marks in the room list and in the room, and the Chinese factory labels now install with Stable updates.
- Fix: when the native room data changed while the battle was loading, the client could treat an OC room as a G改 2.0 room and leave out the OC speed and agility gains. The client now settles the room's system in the waiting room and keeps it through loading and battle.
- A native GameTest that plays an OC, a G改 1.0 and a G改 2.0 room back to back in one client now runs as a pre-release check.
- Requires client Mod 0.6.1, World Mod 0.5.0 and Battle Mod 0.3.1. The server chooses systems per room only in `room` mode, and G改 1.0 also needs the owner's rule file.
- Update through SDGO Mod Manager or the server owner's client package or update, then restart the game client. Server Mod changes need a World and Battle server restart.
