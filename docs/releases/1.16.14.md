## 中文

新增地图与任务导入（Beta）：在 Mod Manager 登记按地图包协议制作的对战地图和 PvE 任务，编译成一个客户端包和配套服务端行。

- 地图包描述地形（高度图与多层地表）、物件（自带 glTF 模型或客户端已有模型）、出生点、天空、雾、小地图和音乐；导入后出现在对战房间的地图列表中，原有地图保持不变。
- 任务协议支持 1..8 个阶段：击破指定单位、坚守时间、限时失败、友军被击破失败、分批刷怪、区域切换和阶段奖励；首领可使用对战 AI。
- 开场、阶段过场和终场动画：镜头关键帧平滑插值、演员机体动作和移动、横幅、特效、音效与镜头震动；过场期间隐藏玩家机体，结束后恢复。人物对话使用游戏自带的头像对话框。
- 编译时检查出生点、刷怪点、演员和传送点是否位于物件内部，以及过场镜头是否低于地面、穿入物件或被遮挡，报错给出过场名、时间和坐标。
- Manager 新增「地图与任务导入」页面：登记、修改名称/模式/服务器/任务、编译、安装客户端包，检查、写入并读回服务端；编号按顺序连续分配，服务端写入在一个事务内完成并拒绝覆盖非导入数据。

## English

New map and mission import (Beta): register battle maps and PvE missions made in the map package protocol in Mod Manager, compiled into one client package and matching server rows.

- A map package describes terrain (height map and surface layers), objects (packaged glTF models or models the client already has), spawn points, sky, fog, minimap and music. Imported maps appear in the battle room map list; original maps are unchanged.
- Missions have 1..8 phases: destroy given units, hold out, time limits, failure when an ally is lost, timed enemy waves, sector changes and phase rewards; bosses can use the battle AI.
- Opening, mid-mission and ending cutscenes: smooth camera keyframes, actor animations and movement, banners, effects, sounds and camera shake. Player units are hidden during cutscenes and restored afterwards. Character dialogue uses the game's own portrait dialogue panel.
- The compiler refuses spawn points, waves, actors and warp points inside objects, and cutscene shots below the ground, inside objects or with a blocked view, naming the cutscene, time and position.
- New Manager page "地图与任务导入": register maps, edit names, modes, servers and missions, compile, install the client package, and check, apply and read back the server rows. Numbers are assigned contiguously; the server write is one transaction and never overwrites non-import data.
