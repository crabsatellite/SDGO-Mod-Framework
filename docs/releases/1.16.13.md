## 中文

活动扭蛋机的机体奖品会自动补充到机体图鉴的获取途径，图鉴机台号与扭蛋页面一致。

- 发布活动奖池时，为全部有效机体奖品生成获取途径，包括已导入机体；无需再次导入或安装额外联动 Mod。草稿、停用活动和零权重奖品不计入。
- 原生图鉴的普通扭蛋来源按页面编号显示，例如内部 ID 15201 显示为 152 号。数据库、奖池和网络身份保持原值。
- 保留原有商城、活动、收藏扭蛋说明和设计图获取信息。活动奖池发生变化后，重新生成并发布客户端内容即可同步。
- Manager 机体预览中的获取途径也使用页面编号。

## English

Activity capsule unit rewards now appear automatically in encyclopedia acquisition sources, with machine numbers matching the capsule page.

- Publishing an activity pool generates sources for every active unit reward, including imported units, without reimporting units or installing another integration Mod. Drafts, disabled activities and zero-weight rewards are excluded.
- Native ordinary capsule labels use page numbers: internal ID 15201 appears as machine 152. Database, pool and network identities keep their original values.
- Existing shop, event, collection capsule and blueprint information is preserved. Regenerate and publish client content after changing an activity pool to update the sources.
- Manager unit previews also use page numbers for acquisition sources.
