## 中文

OC 六维强化：机体表中的每台机体都有成长行，「终极强化」页面对所有机体都能打开。

- 之前只有 World 服务端 Mod 首次安装时机体表里已有的机体才有 OC 成长行；之后加入的机体（例如导入的机体）没有 OC 档，点击「终极强化」只会切到「经验值转换」，OC 页面不出现。
- 现在每次 World 服务端启动时，为机体表中的每台机体确定成长行：原版 OC 目录收录的机体使用原版数据，其余机体按等级公式（成长行编号 = 1010000 + 机体等级）。运行期间新加入的机体在首次打开 OC 档时按公式补上。
- 服主可以在 World 服务端 Mod 目录放可选的 `oc_growth_overrides.tsv`，逐台指定成长行；文件里列出的机体优先，删去后恢复默认规则。格式和日志见 OC 六维强化指南的「机体成长行」一节。
- 需要 World 服务端 Mod OC 六维强化 0.5.1，更新后重启 World 服务端；客户端和对战服务端 Mod 不变。

## English

Over-custom: every unit in the unit table now has a growth row, so the 终极强化 page opens for every unit.

- Before, only units already in the unit table when the World Mod was first installed had an OC growth row; units added later (for example imported units) had no OC profile, and clicking 终极强化 only selected 经验值转换 without showing the OC page.
- Every World server start now sets the growth row of every unit in the unit table: units of the original OC catalogue use the original data, every other unit uses the grade formula (row number = 1010000 + the unit's grade). A unit added while the server runs gets the formula row when its OC profile is first opened.
- The server owner can set any unit's row in the optional `oc_growth_overrides.tsv` in the World Mod folder; listed units take the file's row and return to the default rule once removed. See "Unit growth rows" in the Over-custom guide for the format and the log line.
- Requires the World Mod Over-custom stats 0.5.1; restart the World server after updating. The client and Battle Mods are unchanged.
