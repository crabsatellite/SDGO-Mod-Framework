# SDGO Mod Manager 1.16.65

## 中文

- 修复 U.E REEF 等地图上对战 AI 复活时被困在真人出生点的问题。AI 使用开局分配的原版出生点，继续执行原版碰撞检查。
- 宇宙地图的寻路长时间给不出可用路点时，AI 会尝试通过原版碰撞检查的脱困动作。

## English

- Fixed PvP AI getting stuck during respawn on maps such as U.E REEF. When native playback chooses a human start point, the AI uses its assigned map start point and retains the original spawn collision check.
- Space-map pursuit can recover when an unfinished route leaves the AI stationary without a steering waypoint.
