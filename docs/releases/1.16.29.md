## 中文

扭蛋机编辑器自带 35 台可编辑的普通补齐奖池，作为首次安装默认配置和服主模板。

- 选择匹配的客户端与服务端、将现有目录 JSON 留空后保存，即可自动生成原有 78 台加 35 台补齐机，并配套安装两端。
- 默认机体、价格和概率可继续编辑。恢复默认只处理这 35 台；升级保留已有作者修改、自定义机和其他内容。
- 模板只包含配置与本地资源引用，不含游戏原文件或图片。所需机体、等级或原生基线不匹配时整体拒绝，防止半套奖池。
- 默认图片映射随 Manager 提供，不依赖作者电脑上的额外映射文件。玩家无需运行 SQL。

## English

The capsule editor includes 35 editable fixed acquisition pools as first-install defaults and owner templates.

- Select a compatible client and server, leave the existing catalog JSON blank and save to automatically prepare the original 78 pools plus 35 supplementary pools and install both sides together.
- Unit choices, prices and weights remain editable. Restore affects only these 35 pools; upgrades preserve authored changes, custom capsules and unrelated content.
- The template contains configuration and local resource references, with no original game files or artwork. Missing units, grade mismatches or an incompatible native baseline reject the complete operation.
- Manager carries the default portrait references without an extra machine-specific lookup file. Players never run SQL.
