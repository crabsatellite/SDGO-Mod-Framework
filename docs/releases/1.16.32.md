## 中文

商城模组内置五类可编辑默认预设，首次绑定空商城工作区后自动上架，无需另行导入样例包。

- 包含永久机体、租赁机体、副官、设计图和其他道具。沿用目标服现货的实际原生模板、价格、币种、期限或数量，保留来源的购买与赠送条件。
- 在 Manager 继续编辑、下架或删除；升级与再次绑定保留修改。已有目录和服务器归属记录不会被空工作区覆盖。
- 配置了客户端时同步生成显示和获得方式数据，随服主提供的客户端包或更新分发。不包含私有机体、素材或固定的本服商品数据。
- 修正商城符号表与模组声明的差异，保证匹配的显示更新可以正常导出。
- 开发用原生购买检查覆盖五类默认预设，并处理其他道具的原生追加确认；真实扣款、到账及重新登录持久化分别核对，不把只读预览当购买通过。

## English

The shop module includes five editable default presets. First binding an empty shop workspace lists them automatically, with no separate example-package import.

- Includes permanent units, rental units, operators, blueprints and ETC items. Inherits the destination stock's actual native template, price, currency and validity/quantity, retaining its purchase and gifting conditions.
- Continue editing, unlisting or retiring them in Manager. Updates and later bindings preserve changes; empty workspaces cannot overwrite existing catalogs or server ownership records.
- A configured client receives matching display and acquisition data through the server owner's client package or update. No private units, artwork or fixed owner product data are bundled.
- Aligns shop host symbols with the module declarations so matching display updates can be exported normally.
- Developer native purchase checks cover the five preset types, including the original additional ETC confirmation. Real debits, delivery and later-login persistence are verified separately; read-only previews are never reported as purchases.
