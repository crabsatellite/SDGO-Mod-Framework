## 中文

新增两个独立的客户端自动修复。

- 机体列表的顶点、索引缓冲或模型加载失败时，释放本次新建资源，按原生路径清理并使用现有缩略图；正常加载继续使用原生流程。
- 特殊攻击随机目标数量非法时，返回原函数已有的零向量失败结果，阻止使用非法余数读取目标列表。空列表、有效数量及非随机目标路径保留原生处理。
- 特殊目标保护限定在消费端；写坏对象或数量的来源仍未确定，不能据此宣称全部内存损坏已修复。
- 通过 SDGO Mod Manager 或服主提供的客户端包或更新取得新版，更新后重启客户端。

## English

Adds two independent automatic client fixes.

- Failed vertex/index-buffer uploads or model loads in the unit list release their new resources, preserve native cleanup and use the existing thumbnail. Successful loads retain the native path.
- Invalid random special-target counts return the function's existing zero-vector failure result before unsafe division or indexing. Empty lists, valid counts and non-random selection retain native handling.
- The special-target fix contains the consumer defect. The source of the corrupted object or count remains unresolved; this is not a claim that all memory corruption is fixed.
- Update through SDGO Mod Manager or the server owner's client package or update, then restart the client.
