# 中文输入法候选与提交修复

`ime_fix` 1.1.1 修复 Windows 中文输入法候选窗请求被隐藏、选词后残留拼音字母的问题，
并保留原有中日韩输入法提交长度修复。中文提交按原来的拼音范围替换，保留合法的英文、数字前后缀。

## 使用

已安装客户端运行 `update.bat` 同步最新 Git 版本，正常重启游戏。
Mod 在 SDGO Mod Manager 的「修复归档」中列出；较旧 Manager 可能仍叫「输入法提交修复」。
排查时在「显示开发信息」里开关本修复或诊断日志，重启客户端生效。

不需要更换输入法、另开启动器或修改 Windows 注册表。候选窗、拼音选词、空格/数字选词、
Esc 取消、中英混输和焦点切换都在游戏原生输入框中使用。

## 机制

- 仅在已核对的提交调用点纠正 UTF-16 字节/字符长度，其余系统 API 调用保留原合同。
- 针对游戏的中文隐藏 EDIT 恢复原消息已请求的候选窗标志，保留其他 UI 位。
- 原生结果处理错误地用新中文长度删除旧拼音。Mod 在结果消息前保存旧拼音，
  仅在对应显示片段与它逐字相等、调用方/对象/来源/位置均匹配时改为删除旧长度。
- 输入结束时用游戏自己的字符串函数清理预编辑缓存。其他字符串替换保持原生行为，
  不通过扫描、裁掉末尾英文猜测删除范围。

## 诊断

Manager 开发信息中的 `Trace` 默认关闭。日志只记录事件与长度，不记录输入文字。
`native IME result erase count corrected` 表示结果替换长度已纠正；
`preedit/display guard mismatch` 表示范围未精确匹配，保留原生处理，需要按该轮日志排查。

开发路径及验证边界见[调查记录](investigations/windows-pinyin-input.md)。
