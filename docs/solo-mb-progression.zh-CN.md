# MB 轻度养成

[English](solo-mb-progression.md) · [战斗奖励](battle-rewards.zh-CN.md)

在 SDGO Mod Manager →「战斗奖励」中，点击「预览并应用轻度养成方案」，核对后确认。
它保留 GB、现有倍率及其他贡献规则，调整下列 MB 并启用日周目标。也可分别修改日周奖励。
旧配置默认关闭，升级不会立即给现有玩家发钱。玩家无需另装 Mod、打开管理器或点击领取。

| 目标 | 固定 MB |
|---|---:|
| 每日首个有效对局 | 100 |
| 每日累计 3 局，额外获得 | 400 |
| 每周累计 12 局，额外获得 | 1,000 |

三个目标共用进度。单人任务、带 AI 对战均可；失败也可累计，不要求 MVP、多人或连续登录。
每局须通过原生结算资格、至少 180 秒有效参战，并有实际伤害、击杀、助攻、小怪或 Boss 贡献。
0 击杀但有伤害可以计数。短局、纯挂机、观战、AI 账号不计数，不通过浏览器上报战绩。
普通战斗奖励沿用原规则；日周固定奖励不乘基础、双倍、难度或人数倍率。

任务一倍通关 MB 保底为 2、失败 0.5、一倍总上限 5；对战胜/负/平 MB 保底为 5/3/4，
MVP 额外 10。默认十倍普通时段、单人普通任务通关至少 20 MB，Boss 贡献另算。
公共初始值保持保守，服主可配置首局金额、日/周目标局数与固定金额，升级保留已有配置。
每日北京时间 00:00、每周一北京时间 00:00 重置，同一钱包账号跨对战服务器共用进度。
周期聚会奖励有独立规则与可配置时区，见战斗奖励指南。

## 按本服物价设置

先选希望玩家通过几次上线获得的商品，再按价格倒推固定补给，同时纳入正常对局、周常、聚会和节日收入。
每周固定收入可按「上线天数 ×（每日首局 + 每日目标）+ 周目标 + 聚会奖励」估算。
Manager 显示每周四天达到日目标的预算示例，它不会修改商店价格，也不承诺相同的积累天数。

## 安装与一致性

从 Manager 更新奖励 Mod 和配套管理端，安装计划会增加本工具的三个进度表/过程；保留原生钱包过程。
先正常结束对应对战服务的对局，再按现有奖励安装流程更新 DLL，重开对应服务器。
不要只复制规则文件给旧 DLL。日周奖励要求 v2 或更新的配套原生作业/工作器协议，协议不匹配时拒绝新奖励结算并保留原游戏通路。
旧 v1 待处理作业仍可处理原 MB，但没有可靠的时间/参战元数据，不追补日周奖励。

Manager 发布策略时先持久保存按摘要命名的完整快照，原生结算冻结同一版本和同一结束时间。
工作器按原始结算时间归属日期；停机跨日或跨周不会把旧对局计到新周期。
每局进度、固定奖金、原生钱包入账与进度回执在同一事务内。正常对局 MB 保留原事务。
两个事务之间或写本地确认前崩溃，会用同一作业安全补齐，不重复计局、不重复到账。
改变规则不会再发已领取的当天/当周里程碑。关闭只作用于之后的新结算；原队列按原快照处理。
请保留 runtime/policies、作业、回执及数据库进度记录，不用删除记录的方式重置奖励。

服务端不新增玩家领取窗口；沿用原生现金余额通知与登录/商城查询刷新。
