# 完整对战 All Map

[English](all-maps.md) · [返回功能目录](../README.zh-CN.md#玩法扩展)

把房间的 **All Map／随机地图** 扩展为完整对战地图目录。任务专用地图仍只在任务模式中使用。

| Mod | 安装位置 | 作用 |
|---|---|---|
| `all_maps` | 每个提供房间的 BattleServer | 从完整对战地图池权威抽取并公布本局地图 |

无需客户端 Mod。房间继续通过游戏原生的开局和地图通知流程接收所选地图。

## 使用

1. 停止需要更新的 BattleServer 实例。
2. 在 **SDGO Mod Manager** 中，为所有提供这些房间的 BattleServer
   启用「完整对战随机地图池（服务端）」。
3. 保存修改，重新启动相关 BattleServer。
4. 创建对战房，在原生地图选择器中选择 **All Map／随机地图**。

此功能没有用户参数。关闭 Mod 并重新启动后，对应 BattleServer 恢复原生地图池行为。

## 地图池规则

Mod 读取游戏已经加载的原生地图目录。地图只要带有下列至少一种对战标志，就会加入一次：

- 普通
- 死亡竞赛
- Grid
- Tag
- 队长

支持的对战房间模式共用这个并集。房间的战斗模式和规则保持原样，只扩展 All Map 的选图范围。

下列选择继续使用原生规则：

- 指定的固定地图
- Hot Map
- Fast Map
- 自选随机集合
- 任务模式和特殊 AI 模式

目录第 0 行是原生随机地图标记，不会被当作可玩的地图。任务专用图、训练专用图和仅存在于
资源包而未进入当前地图目录的地形不会混入对战。

## 兼容性与排错

Mod 支持 `BattleServer-548A891D-0046C000`。程序版本不匹配或所需符号未通过校验时不会启用。
服务端权威抽取时会在日志写入 `All Map mode=`。

| 现象 | 检查方法 |
|---|---|
| All Map 仍使用原来的小地图池 | 确认提供房间的 BattleServer 已启用 `all_maps`，重启并查看日志 |
| 不同房间的地图池行为不一致 | 确认所有可能提供这些房间的 BattleServer 都启用了 `all_maps` |
| 房间开局被拒绝 | 查看服务端日志中的目录或随机源错误；Mod 会拒绝抽取，不会悄悄选择目录第 0 行 |
| 固定、Hot、Fast 或自选随机没有变化 | 这些选择按设计继续使用原生规则 |

## 开发者说明

服务端读取原生 MapFile 链表，并用拒绝采样的系统随机数进行无偏抽取。Mod Hook 权威的
房间开局选图，客户端继续通过原生流程接收所选地图；Mod 不改写地图标志或地图资源。

针对性规则测试：

```powershell
ctest --test-dir build/native -C Release -R all_maps_offline --output-on-failure
```
