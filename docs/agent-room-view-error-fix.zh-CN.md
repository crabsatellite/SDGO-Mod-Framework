# Agent 房间视图错误转发修复

原版 AgentServer 会把原生房间视图错误回复 `0x0880` 路由给正确的已登录玩家，
但只转发 BattleServer 八字节回复的前四个字节。错误字段因此缺失，客户端会继续
读取无关内存，在房间操作期间可能弹出与实际情况无关的错误。

这个服务端自动修复只在已验证的 Agent 转发调用处保留完整的八字节回复。目标
玩家、原生错误码、发送标志、房间逻辑和其他数据包都保持原版行为。Mod 默认启用，
没有可调设置。

请把 Mod 安装到所有承载玩家的 AgentServer，然后重启这些 AgentServer 进程。
客户端不需要配套的客户端组件。如果房间操作确实失败，客户端仍会收到并显示原生
错误。
