# 登录页面机体展示

[English](login-showcase.md) · [返回功能目录](../README.zh-CN.md)

在 **SDGO Mod Manager → 登录页面机体展示** 中选择登录页面展示的机体。

- **按等级选择：** 可以同时勾选多个等级。默认勾选 **SS、SR、SU**，普通 S 需要单独选择。
- **全部机体：** 使用当前客户端已登记、可展示的所有初始形态机体。
- **最近注册：** 设置包含最近新增的多少台机体。按客户端图鉴的登记顺序选择，不以机体编号大小或文件修改时间推测新旧。
- **指定机体：** 在已安装的机体目录中按名称搜索，勾选需要展示的机体。

同次游戏运行内，候选池按打乱后的顺序展示，一轮用完前不重复选择。保留登录页面的原生展示方式，配置在下次启动游戏时生效。候选池为空或暂不可用时，保留游戏原有的登录机体选择。

超大型替换机体会在需要时适当缩小，小型机体不会放大。登录页仍使用原生镜头和展示方式，因此外沿武器或翼部仍可能贴近原生近景边缘。完整客户端更新会保留玩家选择的展示方式和机体配置。

导入机体在配套客户端内容安装并启用后进入候选范围。此配置只影响登录页面，不发放机体或修改战斗数值。更换内容包后，如指定名单中的机体已经不可用，请调整名单或更换选择方式。

原生读取挂钩由启动崩溃修复统一管理。可选的模型缩放符号缺失时，扩展展示停用，原有的机体缺失防护继续生效。更新完整框架包可恢复展示功能。
