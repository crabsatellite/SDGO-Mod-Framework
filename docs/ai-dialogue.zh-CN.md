# AI 机师互动台词

AI 可以根据当前战况说一句符合机师口吻的台词，例如被你击破后的不甘、击破你后的调侃，或队友的集火建议。功能默认关闭，需要自己的 DeepSeek API 密钥和正在运行的 Mod Manager。

## 开启

在 Manager 添加游戏客户端，打开“AI 机师互动台词”，选择客户端，填写并保存本机 API 密钥，启用功能，再启动台词服务。首次安装组件需要重新打开游戏。普通设置、提示词和机师设定保存后自动读取。

密钥使用 Windows 当前用户的 DPAPI 加密，保存在 Manager 的私人工作区，并绑定保存时的 API 地址；更换地址后须重新保存密钥。配置包、服主内容源、通用 Manager 发布包和“复制给 AI”说明不包含该密钥。每位玩家填写自己的密钥，关闭服务即可停止请求。

| 设置 | 默认值 | 含义 |
|---|---|---|
| 功能开关 | 关闭 | 关闭时不调用 API |
| 触发方式 | 概率 | 可选每次符合条件的事件或按概率触发 |
| 触发概率 | 35% | 每次符合条件的原生事件单独抽取 |
| 可见范围 | 仅自己 | 可切换为本局战斗频道，所有参与者可见 |
| 发言间隔 | 8 秒 | 设为 0 可逐次处理；仍受请求并发和调用上限限制 |
| 每局调用上限 | 24 | 失败的请求也计入，避免无限重试 |
| 队友建议 | 开启 | 分配给你的 AI 队友可建议集火 |
| 模型 | `deepseek-flash` | 快速模型，关闭思考；可配置兼容的快速模型名称 |
| 语言 | 简体中文 | 可按喜好修改 |

请求在 Manager 后台异步执行，游戏不会等待 HTTP 返回。每个客户端同时只保留一个请求，忙碌、过期或超过上限的事件会跳过。请求超时、切换场次、离开战斗、关闭功能或配置改变后，不再显示旧回复。

## 谁对谁说

敌方 AI 只在你击破它或它击破你时回应，不会用你的 API 为其他玩家之间的无关击破生成台词。队友建议按同队真人的身份确定归属，避免多个客户端为同一个 AI 重复生成相同的自主互动。

原生战斗文字区显示 `狂飙迪亚斯：台词`，使用实际出击机体名称，不附加编号和箭头。多人对局时，模型在台词正文中自然称呼目标玩家。

仅自己可见不会发送聊天包。战斗频道使用本局原生房间聊天，由使用该功能的玩家账号发出并带明确 AI 标记，不伪造服务器机师身份。接收方也需要配套组件才能还原中文；组件默认关闭仍保留该消息的显示兼容能力。它不会发送到大厅、世界或公会频道。

## 战况与人设

上下文包含击破者、被击破者、出击机体、敌友关系、当前存活名单、本局已观察到的死亡次数、当前第几条命，以及从进入战斗起经过的时间。

常规战使用可持续复活的状态。死亡竞赛及接力模式结合原生生命额度和机体消耗，区分仍在战斗、等待复活、最后一条命和已经出局。其他模式无法确认的复活额度保留为未知，不根据血量为零就声称无法再次出击。中途加入时，已观察到的死亡次数不代表完整历史。

当前选中的武器只作为提示，不能冒充已经确认的致死武器。同时瞄准某机体的 AI 数量也不等于实际命中过它的玩家人数。模型可根据人数劣势、集火迹象和角色性格不服气、调侃对方运气或认可配合，但不能虚构已经完成的战术。

`personas.json` 可按机体编号或名称片段指定机师、作品和性格。明确编号优先；没有匹配时，让模型根据机体与原作背景推测口吻，量产机可以采用普通士兵人设。身份不确定时不要求自报角色姓名。`prompt.txt` 控制台词风格，可直接在同一 Manager 页面编辑这两个文件。

## 排查

没有台词时，先看后台服务是否运行、本机密钥是否已保存，以及客户端是否已重新启动。HTTP 402 表示提供方拒绝计费请求；检查 DeepSeek 账户额度。概率、间隔、每局调用上限、只处理本人事件和过期丢弃均可能使部分事件没有台词。

台词发送涉及当前战况，启用功能后这些字段会提交给所选 API 提供方。聊天历史、账号密码、API 密钥和数据库连接信息不进入提示词。

## 开发者说明

`match_ai` 的 `battle.events.client` 能力通过 `sdgo/match_ai_events.h` 公开主线程只读事件。消费者只复制本次原生对象和通知的数据；网络由 Manager 的 `battle.ai_dialogue` 服务处理。磁盘桥使用会话、场次、请求序号和有效期匹配，协议定义位于 `mods/ai_dialogue/protocol.h`。

原生聊天有 80 字节限制，房间广播使用范围严格限定的 UTF-8 标记，输出更短的台词。`shop_labels` 安装时复用其 `native.text_decoder` 扩展；未安装时使用相同的原生转换入口，避免争抢已有钩子。非本组件的文字沿用原转换。

DeepSeek 请求遵循[官方 Chat Completions 接口](https://api-docs.deepseek.com/api/create-chat-completion/)，固定禁用思考、拒绝 HTTP 重定向，并限制响应长度和等待时间。提供方返回的错误正文与凭据不写入诊断信息。
