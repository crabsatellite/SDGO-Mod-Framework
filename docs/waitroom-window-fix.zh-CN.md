# 房间窗口初始化保护

[English](waitroom-window-fix.md) · [返回功能索引](../README.zh-CN.md)

等待房间服务尚在绑定视图时，Windows 可能先查询窗口图标。原生消息回调会直接访问空视图，
造成建房成功后客户端退出。

`waitroom_window_fix` 在视图为空且消息为 `WM_GETICON` 时，返回回调原本的“未处理”结果，
让应用已有的默认窗口路径处理图标查询。视图就绪后保留原回调参数；其他消息沿原逻辑处理。

客户端组件自动启用，无配置项，在 Mod Manager 的自动修复归档中查看。
安装服主提供的客户端包或更新后重启游戏即可，服务端无需配置。

组件要求匹配的原生客户端 profile 及完整回调指纹；代码不一致时拒绝安装钩子并记录日志。
如果仍然不能进入房间，请在问题反馈中附上客户端日志与进入房间的操作步骤。
