# 房间窗口初始化保护

[English](waitroom-window-fix.md) · [返回功能目录](../README.zh-CN.md)

修复建房成功后客户端偶尔直接退出的问题。

## 使用

`waitroom_window_fix` 是客户端自动修复，没有设置项，在 SDGO Mod Manager 的「修复归档」中列出。
安装服主提供的客户端包或更新后重启游戏即可，服务端无需配置。

本 Mod 只在支持的原版客户端上启用；客户端代码不一致时不安装钩子，并在日志中说明。
如果仍然不能进入房间，请在问题反馈中附上客户端日志和进入房间的操作步骤。

## 开发者说明

等待房间服务还在绑定视图时，Windows 可能先查询窗口图标。原生消息回调会直接访问空视图，导致客户端退出。
本 Mod 在视图为空且消息为 `WM_GETICON` 时返回回调原本的“未处理”结果，交给应用已有的默认窗口路径处理图标查询；
视图就绪后保留原回调参数，其他消息沿原逻辑处理。钩子要求匹配的原生客户端 profile 和完整的回调指纹。
