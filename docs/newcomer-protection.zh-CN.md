# 新手保护

独立、可选的 Battle 服务端模组，为服主指定的玩家提供生命值与普通武器伤害倍率，覆盖任务和对战。玩家不用自行配置保护参数。

在 Mod Manager 中打开**新手保护**，选择对战服务进程，按名字查找玩家并加入本服名单。启用保护、保存后，重启对应 Battle 服务端。需要保护的其他 Battle 进程也要设置。生命和普通武器伤害默认各 **2 倍**，可以分别设置为 1～10 倍。

公开包默认关闭、名单为空。本服名单和倍率只写入对应服务端的 `config.ini`，不进入 Manager 程序、公开 Release 或玩家内容配置档。面板选择的 World 配置文件只用于读取玩家名称。

生命倍率在房间强化和原生生命预算计算完成后作用于最大及当前生命，四机编队和正常复活沿用保护后的生命值。普通攻击先按原生单次输入上限核对，再乘配置倍率，随后继续原生护盾、死亡、击破和结算流程。必杀、防御、移动能力及生命条数保持原规则，其他玩家和 AI 不受影响。不修改库存、机体定义或玩家数据库记录。

名单和倍率修改需要重启对应 Battle 服务端。移除玩家或关闭模组后，下次服务端启动恢复原规则，无需回滚数据库。
