# 商城汉化与中文检索

`shop_localization` 是独立客户端 Mod，在 **SDGO Mod Manager** 管理。它翻译商城名称、说明、
销售选项和商城/扭蛋的机体预览标题，并为机库批量兑换清单及本地 Mod 固定提示提供中文。
与商城租赁标签修复 `shop_labels` 分开注册，商品价格、币种、期限及结算保持原有定义。

## 使用和更新

客户端正常运行 `update.bat` 同步 Git 运行时，关闭并重新启动游戏。Manager 中的「商城中文汉化」
提供商品与机体名称、说明、销售选项、本地 Mod 界面提示、中文搜索五个开关，默认均开启，修改后重启生效。
汉化关闭或未安装时，其他 Mod 继续使用原文字；不需要额外启动器或玩家指令。

机库兑换清单通过机体编号查中文名，保留槽位、等级、数量、奖励及确认流程。
原来的机体规则文件不重写，合法的 FAZZ、GN-XIII 等型号代码保留。
长房名功能只翻固定提示和窗口标题，玩家自己输入的房名、草稿和聊天内容不翻译。

## 中文搜索与筛选

服主先在 Manager 配置已有「商城商品」工作区、WorldServer 和客户端目录，点击 **更新中文检索**。
这是独立操作，不会发布商城草稿、商品或改价。助手备份已知原商品列表与销售选项列表过程，并更新中文别名和检索逻辑；
不改玩家余额、库存、商品行或发货。未知原版、其他工具修改过的过程或异常回执会拒绝覆盖。
更新后无需重启 World；玩家需要更新对应客户端 Mod。

在游戏商城选择分类、等级和支付方式，输入中文名称片段（如「高达」「强袭」）或英文/型号，
再点击右侧**放大镜**应用。原生下拉框改变选择不会立即发送查询，单独打开/关闭下拉框也不查询。
「全部」表示不按该项限制。中文、等级和支付方式可组合使用，翻页保留条件。
原先“搜索全部”忽略等级、热门分支忽略搜索条件的问题在配套服务端检索中一并修正。
两个列表使用同一批有序结果和分页条件，使旧商品在全部和中文搜索中也能正常显示图标、价格及购买／赠送预览。
两个过程在同一事务内检查、备份和更新；任一个过程有外部修改都会拒绝覆盖。

中文或中英混合查询最多 36 个 UTF-16 单元（大部分汉字各占一个，生僻扩展字可能占两个）；
超长会提示并保留输入，不截断发送。英文和原生泰文查询仍走原生编码；`~CN:` 是内部中文传输标记。
服主未更新检索时，可在 Manager 关闭「中文关键词搜索」继续使用原生英文查询。
新增或改名商品后再次点击「更新中文检索」；已经发布为中文的商品原名也会直接参与中文查询。
原生服务端名称与客户端显示名存在租赁前缀、空格或历史拼写差异时，词典以商品编号和原名精确绑定；
英文及型号也能按显示名查询。

## 新商品与词条

新增商品名称和销售选项必须包含中文，可保留型号；旧工作区不会被重置，缺中文的商品补齐后再发布。
商品编辑、导入和发布均执行同一要求。客户端与服务端配套组件经既有 Git 更新分发。
现有英/泰/韩文说明逐条翻译，数量、百分比、期限和型号保留；源文损坏、截断或不确定创意名明确标注。
未来未登记的文字保留原文，服主已经填写的中文商品名保留。

开发路径、自动验证范围及原生接口见 [检索与汉化参考](investigations/shop-search-localization.md)。
