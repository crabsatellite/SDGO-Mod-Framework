# 商城汉化与中文检索

[English](shop-localization.md) · [返回功能目录](../README.zh-CN.md)

汉化商城的商品名称、说明和销售选项，以及商城、扭蛋页面的机体预览标题；机库批量兑换清单和其他 Mod 的固定提示
也使用同一套中文名称。商城可以按中文名称搜索，并与等级、支付方式组合筛选。

商品价格、币种、期限和结算保持原有定义。租赁/永久标签由独立的[商城租赁与中文选项修复](shop-labels.zh-CN.md)负责。

## 使用

`shop_localization` 是客户端 Mod，玩家通过服主提供的客户端包或更新获得，更新后重启游戏即可。
SDGO Mod Manager 的「商城中文汉化」提供五个开关，默认全部开启，修改后重启游戏生效：

| 开关 | 作用 |
|---|---|
| 汉化商品与机体名称 | 商品名、机体预览标题，以及机库兑换清单里的机体名 |
| 汉化商品说明 | 商品说明文字 |
| 汉化商城选项 | 购买、赠送窗口中的销售选项 |
| 汉化本地 Mod 界面提示 | 机库管理、长房名等 Mod 的固定提示和窗口标题 |
| 中文关键词搜索（需服务端检索更新） | 允许在商城搜索框输入中文，见下文 |

关闭某项或未安装本 Mod 时，对应位置显示原文；尚未收录的文字也保留原文。
机库兑换清单只替换显示名称，槽位、等级、数量、奖励和确认流程不变；FAZZ、GN-XIII 等型号代码保留。
玩家自己输入的房名、草稿和聊天内容不会被翻译。

## 中文搜索与筛选

### 服主：更新服务端检索

中文搜索需要服务端检索配合。在 Manager 的「商城商品」面板配置好工作区、WorldServer 和客户端目录，
然后点击 **更新中文检索**：

- 这是单独的操作，不会发布商城草稿，也不改商品、价格、玩家余额、库存或发货。
- 它更新商品列表与销售选项列表两个检索过程以及中文别名，原过程先备份。任一过程不是已知原版、或已被其他工具修改时，
  拒绝覆盖。
- 不需要重启 WorldServer；玩家需要更新到配套的客户端 Mod。
- 新增或改名商品后，再点一次。

服务端尚未更新时，可在 Manager 关闭「中文关键词搜索」，继续使用原来的英文搜索。

### 玩家：搜索商品

1. 在商城选择分类、等级和支付方式。
2. 在搜索框输入中文名称片段（如「高达」「强袭」），或英文名、型号。
3. 点击右侧的**放大镜**。只改变下拉框不会立即查询。

「全部」表示不限制该项。名称、等级和支付方式可以组合使用，翻页保留条件。
中文或中英混合的关键词最多 36 个字（少数生僻字按两个计）；超长时会提示并保留输入，不会截断后发送。

## 新商品的中文名

在 Manager 新增商品时，名称和销售选项必须包含中文，可以保留型号；编辑、导入和发布都会检查。
已有工作区不会被重置，缺中文的商品补齐后再发布。服主已经填写的中文商品名优先使用。

## 日志

| 日志 | 含义 |
|---|---|
| `Chinese shop localization ready: <n> dictionary entries, <m> verified shop callers ...` | 汉化已加载 |
| `Chinese shop search bridge ready ...` | 中文搜索已加载 |
| `shop search rejected overlong query ...` | 关键词超过 36 个 UTF-16 单元，未发送（日志不记录关键词内容） |
| `localization caller is not verified: <name>` / `shop localization refused: ...` | 客户端版本不匹配，本 Mod 未加载，商城显示原文 |

## 开发者说明

原生搜索入口用代码页 874 转换关键词，中文在发送前就被破坏。本 Mod 只在两处已核对的商城关键词调用点，
把中文或中英混合关键词编码为保留的 ASCII 前缀 `~CN:` 加 UTF-16LE Base64（上限 36 个 UTF-16 单元、100 字节），
英文、泰文关键词和其他页面保持原生编码。

原生检索过程在「全部」分类下忽略等级，在「热门」分类下忽略所有可选条件。Manager 更新后的过程解码中文关键词，
按已发布名称和商品绑定的别名做 Unicode 子串匹配，对所有分类一致应用等级、子类和支付方式，并用同一结果集计算分页和总数；
原生分类和热门归属、活动排除、10 列输出和排序保持不变。商品列表与销售选项列表共用这批有序结果，
因此旧商品在「全部」和中文搜索中也有图标、价格和购买／赠送预览。两个过程在同一事务内检查、备份和更新。

服务端计费名与客户端显示名可能因租赁前缀、空格、历史拼写或型号格式而不同。词典用 `@search:ProductID:原名`
按商品编号和原名精确绑定，不替换原生显示记录或商品身份；英文和型号查询也会匹配这些别名。

其他 Mod 通过可选的 `SdgoLocalizationLookupV1` C 接口查询机体名、物品名和固定界面文字；本 Mod 缺失或关闭时，
调用方保留原文。现有英、泰、韩文说明逐条翻译，保留数量、百分比、期限和型号；源文损坏、截断或无法确定的创意名会明确标注。

地址、封包和接口细节见[检索与汉化参考](investigations/shop-search-localization.md)和
[机体预览标题记录](investigations/shop-preview-title-fix.md)。
