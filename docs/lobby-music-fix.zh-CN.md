# 首次登录大厅音乐

[English](lobby-music-fix.md) · [返回功能目录](../README.zh-CN.md)

`lobby_music_fix` 恢复首次登录时的大厅音乐。同一次登录中，实际进入第一场战斗之前，
原生大厅请求的 `BGM/0042.mp3` 改为 `BGM/0043.mp3`；进入过战斗后，返房和后续大厅页面
沿用原生的 0042。回到登录界面后开始新的一次登录。加载过程中取消、未实际进入战斗，
不会被计为已经打过一局。

## 安装与设置

这是默认开启的客户端自动修复，在 SDGO Mod Manager 的修复归档中管理。安装客户端框架包
或服主提供的客户端包或更新后，重启客户端生效。支持原生版本
`GOnline-54BE1568-00C97000`，指令签名不匹配时拒绝加载，无需服务端安装或房间指令。

继续使用游戏现有的音乐开关和音量。Mod 将选择的文件交给原版 Miles 播放器，沿用它的循环、
淡入和输出设备设置；战斗音乐、结算音乐和自定义音乐沿用原生行为。关闭音乐时不会强制播放。

两首曲目均由客户端包提供，公开 Mod 不包含音乐素材。缺失 `BGM/0043.mp3` 时保留原生曲目，
并在日志中提示缺失。

## 排错

在 `sdgo/logs/` 确认 `lobby_music_fix` 已加载。原生 BGM 记录包含请求曲目、实际选择曲目、
服务状态和本次登录是否进入过战斗。`stream_open=1` 和 Miles 播放状态可确认原版播放器
已打开并启动音乐流，但不代表扬声器一定有声音；仍需检查游戏音乐开关和音量。

切换依据是本次登录的流程，与账号历史上是否参加过战斗无关。
