# 本服程序包

[English](owner-programmes.md) · [Mod Manager](mod-manager.zh-CN.md) · [内容边界](content-boundaries.zh-CN.md)

本服程序包锁定一个官方框架基线，再加入明确允许向本服玩家分发的客户端补丁。源码留在服主的私有开发仓库，玩家只获取构建后的程序与元数据；机体、素材和共享参数继续作为独立内容层发布。

**玩家只导入一个服主配置地址。** 后续双击 `GOnline.exe`，Manager 下载并校验锁定的程序与内容，在同一事务安装，重新核对远端配置后启动原版游戏。下载或摘要失败时保留现有安装并停止启动；备用地址只能继续下载同一发布物，不能换成其他发布者或默认内容。

直接填写内容地址时，Manager 同时读取该端点的 `profile-source.json`，校验发布者和通道后保存服主声明的完整镜像列表。旧端点可以没有该描述文件；文件存在但无效或读取失败时会报错，不会悄悄丢弃备用源。

已经打开的 Manager 也能接续启动，游戏重启使用 Manager 当前的 Windows 权限。自替换期间网络会话短暂切换时，进度窗口仍跟踪该请求的持久完成回执，完成后自动退出。

## 在 Manager 发布

1. 使用维护者客户端，在更新与管理中审阅要采用的官方基线。开发目录保留预览，不跟随玩家自动更新。
2. 导入单独构建的本服 Mod。`mod.ini` 和 `manager.json` 都声明 `distribution=owner`，DLL 带框架定义的本服分发标记，安装到 `sdgo/owner-mods/<id>/`。
3. 在“发布本服程序”选择独立发布目录、同一发布物的镜像地址、正式／测试通道，并勾选要分发的补丁。Git 支持已有身份的 SSH／HTTPS，也可使用离线目录。
4. 发布锁定该程序修订的配置与内容。测试与正式使用不同目录、地址；只推进程序分支，不会越过玩家配置中的旧版本锁。

程序包只接收模块 DLL、两个清单和可选符号片段，不含原版游戏、服务端 DLL、SQL、凭据或素材。共享参数由内容档渲染，不能改写程序身份或原生接口。

## 分发范围与版本

| 范围 | 安装位置 | 分发方式 |
| --- | --- | --- |
| `public` | `sdgo/mods/` | 官方或分支框架 Release |
| `owner` | `sdgo/owner-mods/` | 明确的本服程序包 |
| `local_only` | `sdgo/local-mods/` | 仅本机安装 |

公开分发检查拒绝本服程序与源码；本服检查仍拒绝仅本机文件，改名或删清单也不能绕过。改变某个模块的分发对象需要新声明、新构建和验收，不能修改旧 ZIP 冒充分发许可。

本服正式／测试通道与官方 Stable／Beta 相互独立。本服确有需要时，可以锁定经过验收的某个官方 Beta。官方版本号保持原样，本服程序与内容分别记录修订；程序和内容的镜像都必须匹配选定的本服通道。

## 清单与安装事务

`owner-programme.json` 使用 `sdgo-owner-programme`、schema 1，记录发布者、通道、修订、官方基线锁、所选 Mod 版本和每个文件的大小／SHA-256。Git 锁定提交；HTTPS 与离线发布保留不可变修订目录，后续发布不会破坏旧锁。

使用本服程序层的配置档为 schema 2，并声明内容通道。旧 Manager 会拒绝该格式，避免忽略补丁后启动。玩家来源中的 `manager_policy=owner` 让配套 Manager 随整套程序更新；需要替换自身时自动交接并继续原启动请求。没有本服程序层的普通配置档保持原有 Manager 更新策略。

安装回执记录完整有效文件及程序／内容修订。共享参数、依赖检查、暂存、安装与失败回滚属于同一事务；登录、显示等个人设置及恢复数据留在本地。

受管玩家目录中，Mod 加载目录内未登记的额外文件会先保存到本地恢复目录，再移出加载路径；普通个人文件保留。检查范围是框架的 Mod 根目录，不代表覆盖所有第三方 DLL 注入方式。维护者目录不会自动隔离开发文件。

## 排错

- 官方基线缺少本服程序能力时会拒绝安装，需要选择配套框架。
- 发布者、通道、修订或摘要不一致时，修复发布物或对应镜像，不换成另一套内容掩盖失败。
- 已安装清单损坏时，可由受管更新替换或隔离，原件保留在恢复目录。
- 回退程序应发布新的配置修订，锁回已验收版本；不能重复使用同一修订号发布不同字节，也不能自动降低修订。数据库仍走服务端维护流程。
- 源码仓库与玩家下载端权限不同。玩家可读的私有 Git 仓库，其其他分支也不能存放服务端秘密。
