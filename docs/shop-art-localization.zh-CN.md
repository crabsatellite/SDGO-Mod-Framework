# 商城图片文字汉化

[English](shop-art-localization.md) · [返回功能目录](../README.zh-CN.md)

`shop_art_localization` 用于汉化已经烘焙进商城图片、无法由普通文本词典替换的文字。

## 使用

通过服主提供的客户端包或更新安装。在 SDGO Mod Manager 中找到「商城图片文字汉化」，
可单独启用或关闭，默认开启，修改后重启客户端。普通名称和说明由[商城中文汉化](shop-localization.zh-CN.md)负责。

## 覆盖范围

当前支持灰色罐装涂料使用的已核实图片。原图中的罐体、箭头和黑色标签条保持不变，
泰文军衔文字会被覆盖，并由原生商城商品行显示 **上士及以上**。价格、币种、
购买条件、商品记录及服务端校验均不改变；未核实的图片保持原样。

若标签未显示，请确认 Mod 已启用并重启客户端，再核对商品是否仍使用受支持的图片。
若客户端原生签名不同，Mod 会停止加载，不会对未知版本强行覆盖。

## 开发者说明

精确映射为 `sprs/17825.spr`。覆盖层是原商城对话框拥有的原生 child，不接收输入，并跟随对应
`Goods3DRender` 商品行的可见状态。翻页、切换分类、搜索、空行及重新打开商城
继续使用原生生命周期。本 Mod 不分发替换后的 SPR、TXR 或其他游戏资源。

商城原生对话框的第 `0` 至 `7` 行包含
`ModShopArtBackground{row}` 与 `ModShopArtText{row}`。两个 child 均禁用输入；
文字 child 的内容必须精确为 `上士及以上`，且只有对应已核实图片行可见时才显示。
